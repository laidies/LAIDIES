# Social

This folder stores Instagram strategy, episode kits, reels, stories, captions, and content banks.

Current older episode kits still live in `social/episodes/`. New Instagram work can go under `social/instagram/`.

Start with:

- `SOCIAL-GROWTH-OPERATING-RULES.md` — sustainable channel and growth rules.
- `SOCIAL-CONTENT-LADDER-AND-SITE-PROMISE-GATE.md` — the seven jobs every
  episode batch considers and the required public-destination proof.
- `episodes/episode-social-content-ladder-template.md` — one reusable weekly
  decision and measurement packet.
