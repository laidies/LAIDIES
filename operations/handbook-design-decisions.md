# Handbook construction — 2026-07-24

## Source truth

The inherited `handbook.html` contained useful, complete town guidance but
presented it as a narrow article: one rounded contents card followed by 27
repeated rounded text entries.

The opening art now uses the existing real trailer frame:

`assets/episodes/trailer/comic/trailer-b25-full-8-stops-tour-guide-comic-v1-1920.png`

It already depicts a checklist and an eight-stop route, so it belongs to the
Handbook's actual job. It is a current production source, not a new generation
and not an approved replacement for the Episode 04 Heroine style lock.

## Construction

- One field-guide opening spread combines the real tour image and the Handbook
  purpose.
- One ruled eight-chapter index replaces the rounded contents card.
- Runtime grouping turns the existing document into eight semantic chapter
  spreads without deleting or duplicating source content.
- Chapter headings form the left margin; content continues on the right like a
  reference guide.
- All 27 former cards are now continuous ruled records. Building names,
  addresses, actions, and What/How/Learn/Earn fields read as one town register.
- The index remains a real anchor navigation and updates its current-location
  state as chapters enter the reading viewport.
- Existing Puffy bookmark hooks remain attached to the original headings and
  entries.

## Visual language

- current light site gradient retained;
- near-black-blue cover panel;
- vivid pink, cobalt, purple, cyan, and coral used as controlled reference
  marks;
- Anton carries the comic-display hierarchy; Jost carries the guide text;
- no rounded card stack, fake book illustration, generated person, CSS object,
  or placeholder asset was added.

## Responsive and functional result

- 1440 × 900 and 390 × 844 pass without page-level horizontal overflow.
- The chapter index becomes an intentional horizontal rail on narrow screens.
- Eight chapter anchors, 27 source entries, every building/activity/reward
  link, both final actions, and all existing puffy hooks remain.
- Direct hash arrival and index clicks place the selected chapter correctly
  beneath the global header.
- No broken loaded images.
- Browser diagnostics show only Plausible's expected localhost warning.

## Art boundary

The current tour image is structurally effective and is already part of the
real trailer. Its darker, gold-route rendering is not the approved Episode 04
Heroine lock. Future replacement art should preserve the guide, checklist,
visible town route, eight numbered stops, and wide composition while moving
closer to the locked dimensional graphic-novel finish.
