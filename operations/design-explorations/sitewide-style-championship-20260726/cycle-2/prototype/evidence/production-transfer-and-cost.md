# SVC-01 production transfer, cost and migration

**Status:** CONTROLLED COMPARISON — NO MIGRATION AUTHORIZED  
**Counting rule:** raw workspace assets are not counted as reusable. Exact-use
reuse remains `UNKNOWN` until each placement passes source, text, identity,
crop, responsive and public-rights review. Bands are relative implementation
bands (`S`, `M`, `L`, `XL`), not dollars or schedules.

## System rules

| Surface | A — one graphic-novel world | B — deliberate dual system | C — functional hybrid |
|---|---|---|---|
| Architecture/rooms | Hard variable ink, faceted light and restrained print grain across exterior and interior; each building keeps its own architecture, time and ritual | Painterly dimensional architecture/materials with no faux-comic outline; episode art remains visibly framed as another medium | Painterly/faceted passive architecture; no graphic edge until a true operated/content boundary |
| Characters | Episode adult-comic identity register everywhere; identity/anatomy reference outranks style | Painterly site portrait plus comic episode portrait for every keeper; the two must remain recognizably identical | Adult-comic keeper inside painterly room, bound by shared light direction, palette, edge colour and contact shadow |
| Operated objects | Same-world ink object with stronger silhouette/local contrast; CSS owns focus/status | Painterly object plus deterministic status/focus ring; do not paste comic ink on one object | Ink/faceted plane begins at documented hit-area/object mask; passive surroundings stay atmospheric |
| Content/results | Comic editorial panels/diagrams with real labels | Painterly editorial illustration unless explicitly framed as an episode artifact | Bounded comic/editorial explicitness for results and teachable content |
| Calm reading | Shared cream editorial plane, restrained/no texture behind prose | Same | Same |
| Episode transition | Panel/gutter/page move; no style swap | Clearly framed issue/screen/page threshold into comic medium | Operated/content surface resolves from atmospheric room into full comic episode |
| Motion | Ink reveal, caption/panel snap, semantic page move | Physical/environmental motion; explicit threshold to episode | Focus/activation resolves edge/halftone once; no ambient shimmer |
| Reduced motion | Instant state, stable orientation | Instant medium label/frame change | Instant mask/edge state |
| Failure | Semantic controls/status/result remain; textless art may disappear | Same | Same; masks cannot carry the only affordance |
