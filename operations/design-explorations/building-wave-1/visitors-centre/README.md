# Visitor’s Centre — inhabited orientation-room candidate

**Status:** `BUILT LOCALLY / CANDIDATE-ONLY — independent review required`

This is not `visitors-centre.html` and imports no production CSS or shared
runtime. It is deliberately a single room: map counter + equal named
directory + truthful destination handoff, with tour/trailer/postcard reduced
to optional physical handoff objects.

Open through a repository-root HTTP server, for example:

`http://127.0.0.1:4173/operations/design-explorations/building-wave-1/visitors-centre/?state=returning`

Supported state probes:

- `?state=returning`
- `?state=card`
- `?state=storage-denied`

The no-JS fallback keeps all 17 direct route links in structural HTML.
