# Checklists

Repeatable weekly checklists and QA checklists.

- `episode-concept-fidelity-gate-template.md` — required before an episode
  substance sheet can be presented at Gate 1. It locks Ali's original intent,
  exposes scope changes, runs a blind reverse brief and separately tests
  fidelity, technical truth, teaching value and LAiDIES episode fit.
- `episode-opportunity-scan-template.md` — used after substance approval to
  decide which weekly/site surfaces genuinely strengthen the episode.
