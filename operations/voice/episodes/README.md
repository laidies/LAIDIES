These are *reference exports*, not the live sources:
- Ep 1 & 2 live text: `issues/issue-01.html`, `issues/issue-02.html` (static HTML).
- Ep 3 live source: `content/issues/issue-03.md` (rendered client-side; ep 3+ pattern).

Production-note sections are stripped from these copies. Re-export when an episode's text changes.
