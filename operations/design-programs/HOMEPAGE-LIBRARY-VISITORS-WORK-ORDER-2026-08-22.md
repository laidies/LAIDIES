Homepage is first, LIBRAiRY second and Visitor’s Centre third.

Preserve LAiDIES casing/Ai treatment, the Homepage masthead and exact copy,
vibrant production colours, section-bounded colour, gradients, halftone,
keylines, hard shadows, direct routes, truthful capability state and current

direction, pale palette, purple/yellow pairing, generic cards, white/black text
boxes, repeated white text, random circles, placeholder icons, invented copy
and public use of the word `Play` are prohibited.

## Acceptance

The program checker and calibrated design-admission tests pass; the candidate
uses only manifest-declared dependencies; maker inspection passes desktop,
mobile and reduced-motion states; the exact candidate is committed and pushed;
the independent gate admits those exact bytes.

## Handoff

Ali receives only the admitted exact candidate and one decision: which
direction is closest. Accepted page units are implemented, committed, pushed,
deployed and publicly verified independently.

## Prohibitions

Do not use historical packets as authority, copy an old prototype wholesale,
generate a whole page as an image, add unmanifested assets, invent replacement
copy, bypass admission, or wait for all three pages before preserving completed
work.
