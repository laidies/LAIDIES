# The Basics · Period 7 — When It Does the Work Instead of Telling You
## Shot-by-shot script + voiceover · SUNNYVAiLE High

**Target runtime 9:00 — the longest class in the curriculum, because it is the one with real
consequences.** Narrator: **The Heroine.** Kit: screen capture (two accounts — an ordinary chat
window, plus one throwaway/demo account and demo folder built for the granting-access
sequence) + voiceover + the classroom title card. No characters, no drawn art, nothing to go
off-model.

**Facts in this class were checked against vendor documentation on 2026-07-22.** Sources at the
foot. This is the single most volatile class in the register — the vendor names for "it goes and
does it" are actively being renamed and retired as of the check date. Re-check every URL below
before filming if that date is more than 30 days old.

## ⚠ Read this before you hit record

**This class shows granting a tool access on camera.** That is the whole lesson, so it cannot be
skipped or faked with a static screenshot — but it is also the single riskiest thing to film in
the entire curriculum.

1. **Build a throwaway account and a throwaway folder before you film anything.** A handful of
   junk files with plausible names — three or four fake "invoices," a couple of duplicates — is
   enough. This is the only folder that gets connected on camera.
2. **Never authorise a real personal account on tape.** Not yours, not scrubbed, not blurred.
   Once a consent screen for a real account has been recorded, the session token behind it is on
   the export whether or not the pixels are visible.
3. **Never show a live consent/OAuth screen tied to an account with real data behind it** — even
   for a second, even mid-scroll. If a beat needs that screen and the throwaway account's own
   version isn't available yet at record time, hold the beat rather than substitute a real one.
4. **Close everything else before you record:** email, calendar, notifications, any browser tab
   with your name in the title, your bookmarks bar. This class rests on proving the
   tool can reach into a folder — do not let it prove that on a folder that isn't the demo one.

## The one thing to go and do
**The next time one of these tools offers to go and do something instead of just answering it, grant
it exactly one folder — the smallest one the task actually needs.** Read the plan it shows you
before you approve it. Open the result yourself before you say thanks.

## The one mistake, stated plainly
**People grant access to an entire folder — a whole Desktop, a whole Downloads — because it's
easier than picking the one the task needs, and that folder also holds things with nothing to do
with the job.** *(Documented — Anthropic's own Cowork-safety guidance names granting broad file
access that "happens to also contain sensitive material unrelated to the task" directly,
alongside leaving approval on a fully-automatic setting for something that needed a human check.)*

## Quotable pull (for the clip / social)
> "You do not check this work by reading it. You open the folder and look."

## Production notes
- **The throwaway account and folder are not optional.** Build them before the shoot, with a
  handful of clearly fake files (three or four made-up "invoices," a couple of duplicates). This
  is the only folder that ever gets connected on camera.
- **Do not speed through the approval screen at 1:30 or 4:20.** She has to be able to read the
  actual grant on her own screen, not take the voiceover's word for what it said.
- **The bad example (0:08) has to be a genuinely reasonable thing to type**, not a strawman — a
  smart person really would ask an ordinary chat to clean up a folder, and it really would only
  describe the steps back. Do not make it look like a silly question.
- **Two tools, not five.** The second-tool cutaway at 6:50 proves the shape is universal.
  Showing more turns a basics class into a comparison and doubles the re-shoot cost the moment any
  one vendor renames something.
- **Do not caption a specific vendor name over the beats that are about the category** (5:20
  through 6:50) — only the second-tool cutaway should carry an on-screen name, and only briefly.
- Captions render **below** the picture, never over it.

## Re-shoot triggers
Any of these and this tape needs re-cutting — nothing else does:
- The vendor's plugin/extension-safety language ("runs on your machine with the same permissions
  as any other program you run") is removed, softened, or no longer applies to the tool shown.
- The three-tier approval-mode structure (ask every step / ask for risky steps / never ask)
  changes shape in the tool shown at 4:52.
- ChatGPT's agent-mode-to-Work transition fully completes or reverses before filming — re-check
  both source pages the day of the shoot regardless, since this was already unstable on the
  research date.
