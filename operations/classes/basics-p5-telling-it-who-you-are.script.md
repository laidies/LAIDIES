## ⚠ Read this before you hit record

**This class opens the same settings panel a memory screen sits next to.** The account picker in
that corner shows a real name, initials, or email. Use a clean account, or crop/blur that corner
before export.

The custom-instructions text typed on camera should be **written for the demo, not pulled from
your real box** — even a plausible-sounding "I'm a tax leader at Amazon" line is a real fact about
a real person once it's in an export. Write generic placeholder text (see the shot list) and type
that instead.

## The one thing to go and do
**Open your custom instructions box and write four lines.** Who you are. How you want it to
sound. What format you want back. What you never want to see again.

## The one mistake, stated plainly
**This box is not private from third-party plug-ins.** OpenAI's own help page states: "If you
use third party plug-ins, then the model may provide plug-in developers with relevant information
from your instructions." Do not write anything in there you would not hand to a stranger.
*(Documented — help.openai.com/en/articles/8096356.)*

## Quotable pull (for the clip / social)
> "Don't write anything in there you wouldn't hand to a stranger at a party."

## Production notes
- **The placeholder instructions text must be genuinely generic** — "I'm a project manager, keep
  replies short, bullets over paragraphs, no sign-offs" — not anything pulled from a real job.
  Write it fresh for the shoot; do not improvise it live from memory of your own box.
- **Do not speed up the menu clicks** at 1:50–2:10 or 4:20–4:40. She has to be able to follow the
  path on her own screen.
- **Two tools, not five.** Claude appears for ten seconds to prove the concept is universal.
  Showing more turns a basics class into a comparison.
- **The Before/After input must be typed identically both times** — same eleven words, same
  capitalization, same punctuation. If the two prompts differ at all, the demo teaches nothing.
- Captions render **below** the picture, never over it.
- Nothing on screen gets read aloud verbatim except the highlighted OpenAI sentence at 3:10.

## Re-shoot triggers
Any of these and this tape needs re-cutting — nothing else does:
- The Settings → Personalization → Enable customization path changes, on web or on iOS/Android.
- The plug-in disclosure sentence is removed or softened in OpenAI's help page (this is the
  entire 3:10–3:40 beat).
- Claude renames "Instructions for Claude" or moves it out of Settings.
- Editing custom instructions starts retroactively changing already-open conversations.
