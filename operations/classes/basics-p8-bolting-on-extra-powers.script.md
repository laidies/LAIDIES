## ⚠ Read this before you hit record

**Two different real risks live in this class, and they are not the same risk.**

1. **The connector demo touches a real account.** A connector reaches into your actual mail,
   calendar, or drive. Use a clean demo account with nothing sensitive in it, or stage the
   Connectors panel without actually completing a real login — showing the list and the toggle is
   enough; you do not need to authenticate a real inbox on camera.
2. **Do not actually install an unfamiliar plug-in from the internet for this shoot.** The whole
   point of §11–12 is that an untrusted local plug-in runs with real permissions on a real
   machine. Proving that live means actually taking the risk the class is warning about. Film the
   Plugins Directory / marketplace **listing screen only** — hover, do not click Install on
   anything you have not already vetted. If you want to show an installed skill actually working
   (the Before & After beat), build and install **your own** one-paragraph custom skill in
   advance — self-authored is the safe case this class describes, and it is the only kind that
   should touch a real account on camera.

**Also close before recording:** any tab with your real name, email address, or client names in
the title bar.

## The one thing to go and do
**Open every skill, connector, and plug-in you already have switched on** and, for each one, answer
the three questions out loud: who built it, where it runs, and what it can actually do.

## The one mistake, stated plainly
**Treating a local plug-in or desktop extension as just as safe as something the vendor hosts in
its own cloud.** It isn't — a local one runs on your own machine with the same permissions as any
other program you've installed there. *(Documented — Anthropic's own guidance states plainly that
its plug-ins "may include local MCP servers that run on your computer with the same permissions as
any other program you run," and instructs installing only from sources you trust.)*

## Quotable pull (for the clip / social)
> "That is not modesty. That is the actual limit of what a scan can catch."

## Production notes
- **Build the custom "weekly report" skill before you film, not during.** It needs to already
  exist and already be authored by you (or your own team) — that is what makes it the safe
  demo case. Do not use someone else's uploaded skill for this beat.
- **Never actually click Install on an unfamiliar plugin.** The marketplace-browsing shots at
  3:02 and 3:36 are look-don't-touch. If a real install is needed for another shot, use only an
  Anthropic-reviewed one from the official directory.
- **Two extra tools at 5:49, not five.** Gemini and Perplexity prove the concept is universal;
  more than that turns a Basics class into a comparison chart.
- **Nothing on screen gets read aloud verbatim** except the Anthropic quote at 3:36–4:23 and the
  OpenAI quote at 4:23–4:56 — those two are the spine of the class and should land as read.
- Captions render **below** the picture, never over it.

## Re-shoot triggers
Any of these and this tape needs re-cutting — nothing else does:
- Claude's Skills toggle moves out of Settings → Capabilities / Customize → Skills.
- Claude's Connectors panel stops requiring a separate "disconnect" step distinct from the

- The "Needs Review" flag on an uploaded skill is removed or renamed.
