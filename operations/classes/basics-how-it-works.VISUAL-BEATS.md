# Class B "How it works" — beat → visual sheet
*The visuals are TEACHING DIAGRAMS, not episode scenes. Town comic/pop-art palette, but every frame does a teaching job.*

## 🔴 The rule for every visual — the MUTE TEST
Freeze the frame, cut the audio. **Does the picture alone still teach the concept?**
- If yes → it's a class visual. Keep.
- If it only sets a mood, or is the Heroine standing in a scene → it's an episode panel. **Reject.**

No character-face renders here (that's where episode art fails). These are diagrams: the engine, the room, words, dials. The Heroine is the *voice*, not on screen.

## Notes
- **3 beats need motion** (#5 learn-loop, #6 predict-building, #7 reason-vs-blurt) — because each concept *is* a process; a static panel can't teach it. The other seven are static diagrams. That's the real difference from the episode stills pipeline: a few animated explanatory diagrams, not scene stills.
- **Emphasis word-bursts** (#10, closer) use the locked comic/pop-art word-burst kit — the one place the episode visual language transfers directly.
- **Production:** each is a Codex render from curated refs (one at a time, text-in-render per the Codex rules); the 3 motion beats are simple 2–4 second loops, not full animation. QC each against the mute test before it ships — that IS the calibration anchor.
