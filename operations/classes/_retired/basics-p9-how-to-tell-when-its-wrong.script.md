## The one thing to go and do
**Ask it for one real fact today. Ask for the citation. Click it before you repeat the fact
anywhere.**

## The one mistake, stated plainly
**Trusting an inline-looking citation that appeared without a search actually running.**
The model does not produce a real citation on its own — a citation only counts if the tool
actually ran a search for that response. *(Documented — OpenAI's ChatGPT Search help page states
directly that citations are only real when search was invoked for that response, and that
ordinary text generation does not produce verifiable links.)*

## Quotable pull (for the clip / social)
> "A citation you didn't click is just a rumor with better formatting."

## Production notes
- **Do not fabricate the plain-text "citation."** Reproduce a real no-search answer yourself so
  what is on screen is authentic, not typed in after the fact — the whole beat depends on it
  being a real screen.
- **Let the cold open stream in real time.** A fast cut past the "nothing to click" moment kills
  the point before it lands.
- **The second click-through (3:02) needs a genuinely mismatched page.** Find one organically —
  a real source that answers something adjacent but not identical — rather than staging a broken
  link. The failure being taught is specifically that the page looks fine.
- **Keep the two example questions visually distinct** (population vs. home price) so the two
  beats read as two separate proofs, not one long demo.
- Captions render **below** the picture, never over it.

## Re-shoot triggers
Any of these and this tape needs re-cutting — nothing else does:
- The search toggle stops living at Composer → "View all tools" → Search icon (or the "/" →
  Search path).
- Citations stop rendering as clickable links once search has run.
- The regenerate-with-search path (refresh icon → "Try again") changes or disappears.
