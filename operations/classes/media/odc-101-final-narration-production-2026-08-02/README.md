# ODC-101 final narration production package

Status: **VOICE AUDITION RECEIVED / HOLD**

This package turns the approved, source-current ODC-101 teaching-media script
into a recordable performance without pretending that the existing macOS
system voice is release narration.

## Scope

The recording covers the approximately 4½-minute real-interface teaching
segment. The complete class also contains the guided Try-On, answer feedback,
assessment and take-home material. The catalogue's longer class runtime refers
to that complete learner journey, not to a requirement for eight minutes of
continuous voiceover.

   catalogue/player.

## Voice and mix boundary

- Warm, smart, conversational adult teaching voice.
- Never cartoonish, babyish, schoolmarmish, breathless or motivational-speaker
  copy.
- Meaning and practical caveats matter more than speed.
- Use Hope — upbeat and clear—with the same accepted provider voice ID, Eleven
  v3 model and settings across the opening-day classes. Do not let
  individual classes drift into unrelated narrators or settings.
- Keep square-bracket performance cues inside one continuous Studio chapter;
  do not generate the narration scene by scene.
- Confirm Eleven v3 before every render. On unsupported models, bracketed audio
  tags may be spoken as literal script.
- Final delivery target: approximately -16 LUFS integrated and no higher than
  -1 dBTP. Measure the assembled master, not the voice file alone.
- No music bed may obscure a word or turn the lesson into an advert.
