## ⚠ Read this before you hit record

**The screens in this class are the ones with your real work in them.** A project sidebar shows
every project you have, by name. A knowledge base shows every file you have added, by filename.
Both are visible the moment the window opens, before you have typed anything.

Two safe ways to shoot it, pick one:
1. **A clean account.** Set one up, make one throwaway project with a made-up name (a fake
   client, a fake budget), and film that. Best option — nothing to blur, nothing to explain away.
2. **Your own account, scrubbed.** Screenshot the sidebar and the knowledge-base list first, read
   every name on them, and blur anything that identifies a real client, a real person, or real
   figures. Do not rely on doing it in the edit — a filename in a sidebar is easy to miss.

⛔ Do not film your real project list or your real knowledge base unblurred "just to show the
idea." Once it is in the export it is in the export.

**Also close before recording:** email, calendar, message notifications, any other browser tab
with your name in the title, and your bookmarks bar.

## The one thing to go and do
**Open a project (or its equivalent) and move one piece of material you keep re-explaining into
its knowledge base — not into a chat.**

## The one mistake, stated plainly
**A project is not one shared memory across every chat inside it.** Context is not shared between
chats in a project — only what has actually been added to the project's knowledge base is. A fact
you typed in one chat is invisible to the next chat, even in the same project, even seconds later.
*(Documented — Anthropic's own Projects help page states this plainly.)*

## Quotable pull (for the clip / social)
> "Say it in a chat, and it lives in that chat. Put it in the folder, and every chat inside can
> reach it."

## Production notes
- **Same account, same day, back to back.** The bad and good takes have to come from the same
  session or the comparison isn't honest.
- **Do not tidy the good output.** If it hedges on one figure, leave it hedging and say so.
- **Do not rush the 2:08–3:24 stretch.** This is the single most misunderstood thing about a
  project and it needs the full beat, held, not summarized.
- **Nothing on screen gets read aloud verbatim** except the vendor sentence at 2:30 — the VO
  should never be a caption of the picture otherwise.
- **Two tools, not five.** Ten seconds on a second tool proves the concept is universal; more than
  that turns a basics class into a comparison.
- Captions render **below** the picture, never over it.

## Re-shoot triggers
Any of these and this tape needs re-cutting — nothing else does:
- Anthropic changes the rule and a project starts sharing chat context automatically *(this would
  invalidate the 2:08–3:24 beat entirely — it is the segment most worth re-checking)*.
- The Projects → project knowledge / project instructions menu path changes.
- The deletion behavior changes so that deleting a chat also deletes its attached files.
- The file-size or file-count figures change from the ones cited at 4:28.
