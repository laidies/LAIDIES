## Recap and the one thing to do

1. Use conversation to discover the real job.
2. Consolidate the current objective, sources, decisions, constraints and
   finish line.
3. Execute one bounded stage.
4. Let finish, queue, steer or stop according to consequence.
5. Save the artifact, status and next action.

**Do now:** Complete the LAiDIES working brief for one safe ongoing job.

## The one mistake, stated plainly

Do not assume that a long transcript, memory or Project automatically tells the
model which requirement is current. Availability is not authority.
