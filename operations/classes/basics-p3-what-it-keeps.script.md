# The Basics · Period 4 — What It Keeps
## Shot-by-shot script + voiceover · SUNNYVAiLE High

**Target runtime 5:22.** Narrator: **The Heroine.** Kit: screen capture + voiceover + the
classroom title card. No characters, no drawn art, nothing to go off-model.

**Facts in this class were checked against vendor documentation on 2026-07-22.** Sources at the
foot. Re-check before filming if that date is more than 30 days old — memory is rated HIGH

## ⚠ Read this before you hit record

**Your real memory screen contains real information about you.** This class is literally "look
at what the tool has stored about you", so the recording will show it — your job, your clients, your
health, whatever you have typed over the past year.

Two safe ways to shoot it, pick one:
1. **A clean account.** Set one up, have three or four ordinary chats (a recipe, a work email, a
   holiday plan) so memory has something plausible to show, then film that. Best option — it
   also makes the entries readable instead of a wall of personal detail.
2. **Your own account, scrubbed.** Screenshot first, read every line, and blur anything you would
   not put on a billboard. Do not rely on doing it in the edit — you will miss one.

⛔ Do not film your own memory screen unblurred "just to see how it looks". Once it is in the
export it is in the export.

**Also close before recording:** email, calendar, message notifications, any other browser tab
with your name in the title, and your bookmarks bar.

## A note on the title
This class was drafted as "What It Remembers" and renamed. The tool does not remember — it stores
and re-reads. "Keeps" is mechanically true and just as short, and it holds the line on never
personifying the tool ([[ai-is-it-not-her]]). The vendor's own word for the feature is still
**Memory**, and we use that when naming the setting, because that is what she has to click.

## The one thing to go and do
**Open your memory screen and read every line.** Fix one. Delete one.

## The one mistake, stated plainly
**Deleting the chat does not delete what it kept.** The conversation and the stored note are
separate; each has to be deleted on its own. *(Documented — OpenAI's memory FAQ is explicit that
chats, archived chats, files and connected-app content are separate sources. Anthropic states
the same for Claude: deleting a conversation does not delete the memory entries it produced.)*

## Quotable pull (for the clip / social)
> "The chat is gone and the note it made is still sitting here."

## Production notes
- **Do not speed up the menu clicks.** She has to be able to follow the path on her own screen.
  Dead air on a menu is fine; a fast cut makes it useless.
- **Let the cold open breathe.** The first eighteen seconds are one unbroken shot of a real
  answer arriving. That is the hook, and cutting it up kills it.
- **Two tools, not five.** Showing a second tool proves the concept is universal. Showing five
  turns a basics class into a comparison and doubles the re-shoot cost.
- **Nothing on screen gets read aloud verbatim** except the one entry at 2:16 — the VO should
  never be a caption of the picture.
- Captions render **below** the picture, never over it.

## Re-shoot triggers
Any of these and this tape needs re-cutting — nothing else does:
- The Settings → Personalization → Memory path changes.
- The correction box stops being how you edit an entry.
- Deleting a chat starts also deleting its memory entries *(this would invalidate the 4:10 beat
  entirely — it is the segment most worth re-checking)*.
