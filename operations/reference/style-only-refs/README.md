# Style-ONLY references — the approach that's "getting us there" (Ali, 2026-07-18)

The heroine kept coming out in the model's default clean/flat "pretty-girl" style (see painpoints-log #22).
The move that's working: give the tool a **SET of style examples**, used **strictly for STYLE, never for
identity**. Ali: "i don't want you to use these as references for the facial features or anything — just
the style."

## The recipe (what set of style examples to give)
- **2–4 adult graphic-novel faces** showing the line weight + angular shadow complexity wanted.
- **≥1 daylight example** with natural skin tones.
- **1 full-body example** (shows the style survives at smaller facial scale).
- Optionally **1 "not this"** example for contrast.

## The rule — STYLE-ONLY, hard line
Use the refs ONLY for: **ink density, edge sharpness, number of tonal values, texture, shadow
construction.** Do NOT copy: facial features, identity, proportions, hair, expression, pose, clothing, or
coloring. The **heroine's established face + character canon stays authoritative**
([[heroine-appearance-canon]]). (Same idea as painpoints #17 — words/style not identity — applied to a
whole style-reference SET.)
