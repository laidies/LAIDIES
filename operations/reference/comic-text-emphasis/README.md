# Comic text + emphasis reference library

Ali's locked style references for comic-book display text, punctuation, emphasis words, sound effects,
bursts, and 1990s/Y2K lettering. Use these as **treatment references only**: copy the energy, hierarchy,
ink weight, dimensional edging, irregular letter shapes, and burst construction—not the sample words,
characters, logos, watermarks, or exact compositions.

## SUNNYVAiLE usage lock

- Prefer hand-drawn or deliberately constructed display lettering over plain typeset punctuation.
- Emphasis should use a clear hierarchy: bold face, thick black keyline, optional coloured secondary
  edge, then a hard offset shadow or burst.
- Question marks and exclamation marks should read as designed comic shapes, not ordinary font glyphs.
- Keep episode art vibrant and high-contrast; do not solve emphasis by darkening the whole frame.
- Some source references contain halftone dots. They are **optional source texture only**. For the locked
  Episode 4 clean graphic-novel register, omit halftone dots, stippling, pixel texture, mottling, and
  blotchy grain unless a brief explicitly requests them.
- Never reproduce visible stock-watermark text from a source reference.
