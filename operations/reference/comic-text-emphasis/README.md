# Comic text + emphasis reference library

Ali's locked style references for comic-book display text, punctuation, emphasis words, sound effects,
bursts, and 1990s/Y2K lettering. Use these as **treatment references only**: copy the energy, hierarchy,
ink weight, dimensional edging, irregular letter shapes, and burst construction—not the sample words,
characters, logos, watermarks, or exact compositions.

## SUNNYVAiLE usage lock

- These files define lettering and graphic treatment, not the LAiDIES wordmark
  and not the people-rendering style. See
  `operations/episode-visual-system-lock.md`.
- Prefer hand-drawn or deliberately constructed display lettering over plain typeset punctuation.
- Emphasis should use a clear hierarchy: bold face, thick black keyline, optional coloured secondary
  edge, then a hard offset shadow or burst.
- Question marks and exclamation marks should read as designed comic shapes, not ordinary font glyphs.
- Keep episode art vibrant and high-contrast; do not solve emphasis by darkening the whole frame.
- Some source references contain halftone dots. They are **optional source texture
  only** and may be used for lettering, bursts, cards, or deliberately printed
  surfaces. Do not use noisy texture to replace the master's faceted facial
  modelling.
- Never reproduce visible stock-watermark text from a source reference.
- Ali supplied the 2026-07-23 additions as inspiration for the **site-wide design
  and colour system as well as episode lettering**. Use their vividness and
  contrast as a target, not their literal sample words.
- Use `comic-text-16` as a **background system** for selected chapter cards,
  explainer slides, transitions, and occasional site moments. Replace every
  source word and colour; keep background words subordinate enough that one
  foreground title remains unmistakable. It is not the default background for
  every page.
- Use `comic-text-17` and `comic-text-18` to study compact title construction,
  not as LAiDIES wordmarks. The current approved LAiDIES title treatment remains
  authoritative.
- Use `comic-text-19` for a single decisive impact moment; do not repeat the
  same radial burst behind every heading or button.
- Use `comic-text-20` as a controlled low-density supporting field. Replace all
  sample words and preserve quiet zones around body copy and controls.
