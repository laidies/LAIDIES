## Future adaptation notes

- Banners and headers: use pattern scale and edge placement to keep headings readable.
- Backgrounds: explore both spacious repeats and bold graphic sections; the references are not all verified seamless tiles.
- Resident Cards: keep the portrait, name and card details clear; the open-centre border in image 11 is one useful composition idea.
- Colours: bind the current destination-specific LAiDIES colour authority when adapting; the supplied palettes are inspiration, not a replacement sitewide palette.
- Preserve the lively 90s detail and visual variety Ali selected. No recreation, recolouring or page/Card integration is included in this intake.
