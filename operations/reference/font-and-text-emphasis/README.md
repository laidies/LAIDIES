# Font styling + text-for-emphasis — reference library

> These references govern episode lettering and emphasis treatments. They do
> **not** define the current LAiDIES wordmark. See
> `operations/episode-visual-system-lock.md`.

Reference images Ali shared for **(a) font/lettering styles** and **(b) the "just text on screen for
emphasis" beats** (the comic word-bursts like POW! / AS IF! used in episodes). Pull from these when
rendering title text, the LAiDIES end-title, or an emphasis-text frame. Growing set — Ali will add more.

## Font / lettering styles
- **fontref-01** — **RETROWAVE**: pink brush-script, teal drop-shadow, italic, with an underline swash + full alphabet. ⭐ strong match for the LAiDIES end-title (pink, slightly curved, line underneath).
- **fontref-04** — **POP ART**: bold yellow letters, pink outline + drop shadow, comic burst behind.
- **fontref-06** — **POP!**: pink striped 3-D letters with teal edge + alphabet (navy bg).
- **fontref-07** — **90S! FONTS**: chunky patterned letters (zigzag/geometric fills), black+yellow outline, confetti.
- **fontref-08** — **90s Fonts**: white grungy rounded letters on a pink halftone circle, black outline.
- **fontref-11** — **ADVENTURES IN THE 90s**: red comic 3-D block letters, brown shadow, blue halftone burst.
- **fontref-02 / fontref-05** — 90s pop-art graphic style (starbursts, cassettes, memphis shapes) — palette/energy ref, not a single font.

## Text-for-emphasis (comic word-bursts — the "AS IF!" beats)
- **fontref-03** — comic bubbles: SPLT! POW! ZAP! ZPAM! WHAM! PFF! SWOSH! OUCH! (varied bubble shapes).
- **fontref-09** — comic word-bursts: POP WOW POP! Ooops! ZAP! SUPER SALE! (starburst speech balloons).
- **fontref-10** — sticker-word pile: OOPS / YEAH / COOL / FUN / CHILL / BABY (outlined bubble letters).
- **fontref-12** — pastel comic-panel grid: BOOM / CRAZY GIRL / WOW word-bursts in purple/pink/mint panels with halftone.
- **fontref-13** — **COMIC POP!** purple 3-D comic title lettering (chunky, glossy, drop-shadow, on a notebook-paper burst) — strong reference for a bold comic title/emphasis word.

## Use
- LAiDIES end-title → RETROWAVE (fontref-01) is the closest to Ali's "pink, curved, underline" ask.
- Episode emphasis frames (a funny line on screen, comic-book style) → fontref-03 / 09 / 10.
- Match palette to the [[brand-palette-and-type-lock]] electric accents where possible.
