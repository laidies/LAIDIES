## What to take from these

- A complete page can be made from **cropped visual fragments and words**, not
  only conventional rectangular story panels.
- Use one dominant focal moment, then support it with smaller crops or icons.
- Unify many elements through a tight palette, consistent black ink, and a
  repeated halftone language.
- Let some objects run off the edge; vary scale decisively.
- Keep title lettering integrated into the page instead of floating a generic
  logo over unrelated scenes.
- The blue and yellow repeat examples show how to create breathing room when a
  full collage would be too busy.
- The new impact and repeat references show that the same comic vocabulary can
  scale from a single explosive transition to a quiet site background.
- The brush-stroke reference supports hand-made energy as a **graphic layer**;
  it does not reinstate painterly character or environment rendering.
- The pastel burst reference demonstrates how the comic language can live on
  the site's retained light-gradient system without making every surface loud.
- Ali supplied this library as inspiration for the **entire site design and
  colour system as well as the episode style**, not only for one ident.
