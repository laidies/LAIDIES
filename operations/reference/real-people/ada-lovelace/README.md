# Ada Lovelace likeness-reference status

**Status:** **NO ADMITTED LIKENESS ASSET. This folder is deliberately empty of
portrait files.**

The Episode 04 real-people convention requires a named woman to have an
explicit, licensed likeness reference before production imagery claims her
identity. The research-only historical dossier and URL/date/SHA register live
at:

`../../../product-stewards/episode-media-quality/pilot/p0-1/ada-lovelace-historical-admission-dossier-2026-07-25.md`

and

`../../../product-stewards/episode-media-quality/pilot/p0-1/source-manifest.json`.

The National Portrait Gallery’s 1836 Ada Lovelace portrait is a useful
historical evidence source, but its rights page requires rights-holder
permission for image use. It has **not** been copied here and must not be used
as an image-generation or production reference until a documented licence,
exact asset and independent likeness review are recorded. The local stained
glass Ada image is decorative in-world art, not a real-person reference.
