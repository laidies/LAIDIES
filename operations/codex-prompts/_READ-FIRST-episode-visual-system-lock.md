# READ FIRST — Episode visual work

The canonical rules live in:

`operations/episode-visual-system-lock.md`

Do not copy the rules into a new prompt and paraphrase them from memory. Read
the canonical file, then name:

1. the exact character identity references;
2. the master style-only input
   `assets/episodes/ep-04/pixel/ep04-heroine-face-lock-approved-ali.png`;
3. the relevant saved category reference library;
4. what is locked and what may change;
5. the versioned delivery path.

Generate clean art without text unless the brief specifically requires baked-in
word art. Do not use old welcome-back candidates, the seven-woman ensemble, the
chip-heart logo, or a retired wordmark.
