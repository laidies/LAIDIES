## The brief

Illustrate 100 **Y2K-mall Reading Card faces** for Madame CL<span style="color:#9b3f5f">Ai</span>-O's crystal-ball deck. Each card is a single beloved Y2K object rendered painterly and reverent — the way you'd render a saint's icon, if the saint were a butterfly clip or a Trapper Keeper.

**The vibe:** late-night infomercial meets Anthropologie catalog meets Y2K teen bedroom altar. Warm, glowing, illustrated. Not vector. Not photorealistic. Not cartoon. Painterly.

### The card face
- **Aspect ratio:** 3:4 vertical (portrait card, taller than wide)
- **Format:** PNG, transparent OR warm-cream background
- **Composition:** the object rendered center-frame, occupying ~60–70% of the card, with soft light from above-left. Y2K-mall context (a hint of glitter, wallpaper pattern, plastic mall-fixture edge, or bedroom-carpet texture) softly present at the edges but never dominating.
- **Palette:** warm plum, cream, rose, gold. Same warmth as the LAiDIES saint cards at `assets/saints/y2k-stained-glass-v2/*.png`. If the object is inherently colorful (Lisa Frank folder, glitter body spray, tie-dye), lean into that color inside the plum/rose frame.
- **Register:** hand-illustrated, painterly, dignified. The object should feel *venerated* — like a reliquary, not a product shot. Think illuminated manuscript × mall catalog.

### Card border + flourishes
- Each card carries a **thin rose-and-gold border** (thin painted line, not a mechanical stroke) with tiny corner flourishes — a little rose on each corner, or an Ai-shaped ornament. This is what makes them *feel* like a deck when spread out.
- **NO title text on the card face.** The card name and prose live in the site UI beneath the illustration — the face is purely the painted object.

### Style rules for consistency across all 100
- Same painterly texture across the deck — hand-drawn feel, never vector-flat.
- Same warm chapel-glow lighting — soft top-left source, painted highlights, painted shadow.
- Same rose-and-gold border and corner flourishes on every card.
- Same 3:4 aspect ratio.
- Objects vary; the frame is the constant.
- If the object is a *screen* (Pager, Nokia Brick, AIM Away Message, Away Message, AOL Dial-Up Tone, VHS Tracking Line, CD Skip, Zenon Disc), paint a soft glow radiating from the screen and a legible Y2K interface element on it (a message, a dial-up bar, a static line — nothing that competes with the object itself).
