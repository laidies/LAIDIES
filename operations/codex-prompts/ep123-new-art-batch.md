# ⚠ READ THIS FIRST — HOW TO RUN THIS FILE

**RUN ONE PROMPT AT A TIME.** Do not batch these. Batched image prompts collapse into a template —
every output ends up sharing a layout and a palette. Each scene below is a complete, self-contained
prompt. Generate one, deliver it, then start the next fresh.

**NEVER pick your own reference from the repo.** Every allowed reference is named below with its full
path. Do not forage. Do not "match the existing set" — that instruction has previously caused the
model to grab the worst available asset.

**All text renders IN the generation.** Never leave a blank panel for text to be added afterwards.
