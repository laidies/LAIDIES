# ⚠ READ THIS FIRST — HOW TO RUN THIS FILE

**RUN ONE PROMPT AT A TIME. Do not batch these four together.**
Batched image prompts collapse into a template — every output ends up sharing one layout and one
palette. Each card below is a **complete, self-contained prompt**. Generate card 1, deliver it, then
start card 2 fresh.

**NEVER choose your own reference image from the repo.** Every reference you may use is named
explicitly below with its full path. Do not forage for others. Do not "match the existing set."

**All text is rendered IN the generation.** Never leave a blank panel for text to be added later —
post-applied text has failed every time it has been tried here.

# SHARED SPEC (applies to all four — re-read before each run)

**Register — the locked comic look.**
Reference: `assets/episodes/ep-04/pixel/ep04-scene-11b-timnit-comic-v1-raising-alarm-1920.png`
Take from it: bold black ink outlines · **HARD angular shadow planes** (crisp-edged, cel-shaded,
large flat shapes) · flat vibrant saturated colour · **NO halftone** · realistic anatomy.
NOT soft, NOT painterly, NOT glamour-cartoon. Take the RENDERING from this file, never its composition.

**Layout — copy the STRUCTURE of this card, not its contents.**
Reference: `assets/episodes/ep-03/comic/ep03-open-03-title-comic.png`
Its structure: a large tactile **hero object** occupying roughly the left half · the **title
lettering** set beside it, bold and dimensional · an **"Episode N" ribbon** with the number spelled
in words · period props scattered around the object.

**Why the hero object is non-negotiable:** Ep1 and Ep2's current cards are lettering floating on
abstract pop-art shapes with no object at all, and they fail — you cannot tell what the episode is
about. Ep3's card works because the object tells you before you read a word.

**Period.** SUNNYVAiLE is perpetually **1999**. Every prop must be period-correct. No modern
laptops, phones, flat-screens or contemporary packaging.

**Y2K art direction — BANNED in every card:**
ornate carved or gilded plaques with scroll ends · storybook serif / flourish lettering ·
gold filigree scrollwork borders · climbing roses, rose garlands, pearl strings ·
gem-heart crests · carriage lanterns · wrought iron.
**USE instead:** chunky rounded sans, blocky condensed caps, italic neon script · teal + pink
plastic, chrome trim · the *Clueless* / *Legally Blonde* / *She's All That* production-design register.

**Spelling — this has been raised before and is still wrong in the shipped Ep1 card:**
> **"AI" is written with BOTH LETTERS CAPITAL. Never "Ai".**
The lowercase-i device belongs ONLY to brand words — LAiDIES, SUNNYVAiLE, MAiVENS, LUMINAiRY.
It has never applied to the acronym AI.

**Output:** 16:9, **1920x1080**, PNG.

## Title text, exactly: `The Burn Book Problem`

Re-read the SHARED SPEC above before generating.

**Current card:** `assets/episodes/ep-03/comic/ep03-open-03-title-comic.png`
**Its LAYOUT is the standard for all four cards — keep it.** The composition, the palette, the
scattered props, the ribbon: all correct. **The book itself is wrong and is the only reason this
card is being regenerated.**

**THE FAULT:** the current book is a generic pink diary with a **heart-shaped padlock**. That is a
stock secret-diary trope and it contradicts the episode. The Burn Book was never secret — it was
**passed around**. That is the entire argument of the episode.

**HERO OBJECT — the Burn Book, correctly:**
- A **pink/magenta spiral-bound SCRAPBOOK**, overstuffed, loose pages sticking out at angles.
- The cover is **a collage of cut-out photographs**, each surrounded by handwritten marker
  annotations and scribbled insults. **The collage IS the cover** — not a blank pink surface with a
  motif on it.
- The words `Burn Book` in **ransom-note lettering** — mismatched letters cut from magazines and
  pasted on at angles. Never printed, never embossed, never neat.
- Marker doodles, hearts, glitter, stickers over the top.
- ⛔ **NO padlock. NO lock. NO clasp of any kind.**
- Faces in the collage must be **original illustrated characters** — never real people, never film
  stills, never recognisable likenesses.

Keep the surrounding props (gel pens, star charms, heart erasers) and the `Episode Three` ribbon.

**Tone:** handmade and gossipy, never official or authoritative. Canon: nothing in it was true and
nobody checked — it worked on social authority, not accuracy. It should look like something a
teenager made, because it is.
