## Style rules for consistency across all 21

- **Juicy Couture Y2K benchmark applies to every charm.** Bold silhouettes, high-saturation enamel, chunky proportions, warm-gold hardware. Never dainty. Never subtle. Never realistic-material photorendering. Never modern-minimal.
- **Every charm has a warm-gold jump ring at the top center.** Never omit. Ring is the same warm polished gold across the whole set (matches the site's `--gold` = #d4a853). This is the hardware that connects it to the bracelet's chain link.
- **Same enamel finish** — glossy, painted, with soft highlight glints on curved surfaces. Small rhinestone-style sparkle accents welcome (a single rhinestone gem, a scatter of tiny bright dots on a bow, etc.) where they fit the object.
- **Transparent PNG backgrounds** — checkerboard visible around the charm, no white/plum background baked in.
- **Charm illustrations sized consistently** — each object fills roughly 70–80% of the 512×512 canvas so they appear at similar visual weight on the bracelet.
- **Colors coordinate with each week's palette family**: Week 1 pastels/soft-pinks; Week 2 jewel tones; Week 3 brights and rose-gold. But every charm still shares the shared warm-gold ring so the set reads as one bracelet.
- **No text visible at bracelet-render size (~60px)** — labels/decorative words should be small enough that they read as ornament, not as legible copy.
- **Chunky over subtle.** If a charm reads as delicate at bracelet-size, redraw it bolder. These need to *hold their own* against the chunky gold chain.
