# LIBRAiRY — 90s METAL SHELF FURNITURE (hand to Codex · Tue 2026-07-21 · ships Wednesday)

> **PATH ROOT:** `assets/...` relative to **`Website-homepage/`**. Output → `assets/building-interiors/library-shelf/`.

**Approach (Ali 2026-07-21):** generate the **EMPTY shelving unit** as artwork; the site then places the book
images onto the shelves in HTML. **The LIBRAiRY is CUMULATIVE — books are permanent and we only ADD more over
time** (never swapped out). Keeping books as placed HTML means adding one is adding an `<img>`, not
regenerating the shelf art. **ONE unit is reused for all three sections** (101s / The Tools / Reference) —
only the books and the section name change.
⚠ **Design for growth:** the unit must look deliberate and handsome when only PARTLY FULL — visible open shelf
space should read as "room to grow," never as a sad empty gap. Generous, well-proportioned shelving.

Ali's reference photo: **beige/cream painted METAL** shelving · **slotted adjustable uprights** (the punched

⛔ NO crown molding, NO Victorian woodwork, NO brass, NO ornate anything. It is plain institutional metal.
