# Codex Prompt — LAiDIES Residence Card Stock Avatars

**Purpose:** 24 illustrated portraits — 12 archetypes × female + male versions — that members can pick from when building their Residence Card at MAiKEOVER on MAiN(e). Members who don't want to upload their own photo choose one of these instead. Every member's card lives in the same painterly universe as the 8 Patron Saints at the SANCTUAiRY.

**Signature detail:** every avatar holds a **sacred Y2K-era item** — a talisman that says "this is my era, this is who I am." Turns each portrait into a trading-card-worthy character. Female and male versions of each archetype share the SAME sacred item + character energy; only gender presentation differs.

**Deliverable:** 24 square portrait illustrations (12 archetypes × 2 genders), ~1024×1024 each, plus a 4×6 contact-sheet overview grouped by archetype (pairs sitting next to each other).

## What happens when the images land

1. Ali reviews the set, requests any regens/tweaks (item swaps, personality shifts, etc.)
2. Files drop into `assets/avatars/residence-card-stock/` (or similar path)
3. Wire into card-builder UX at `laidies-card.html`:
   - New "Pick your avatar" section shows all 24 in a grid (with optional filter: All / Feminine / Masculine)
   - Each hoverable → shows the archetype name + sacred item
   - User clicks one → `member_profiles.card_avatar_url` updates to that URL
   - Card preview updates live
4. Upload flow (Piece B, later) transforms photos into the same style
