## Format — IDENTICAL across all 17 (must match the CLAiRE'S set exactly)

- **1:1 square**, 1024×1024 minimum output
- **Item filling ~65–70% of the frame**, centered. Hung garments: slim wire/plastic hanger, hook near
  top-center, garment hanging naturally below. Flat-lay items: item centered at a slight 3/4 angle.
- **Background:** soft radial gradient — center `--cream` (#fffdfb) → edge `--pearl` (#f8eef2). Subtle.
  No pattern, no clutter. **Must be identical to the CLAiRE'S renders** so the sets read as one shelf.
- **Soft rendered drop-shadow** beneath the item (grounded, not floating — but no visible surface, no
  rack, no closet, no wall).
- **Slight sparkle glint** — 1–3 tiny 4-pointed twinkle stars near the item (catalog-sticker energy).
- **Lighting:** soft top-left, gentle. Not dramatic.
- **Illustration idiom:** hand-illustrated digital painting, saturated Y2K palette, editorial-catalog
  finish. **NOT** flat vector. **NOT** photo-realistic. **NOT** 3D-rendered. **NOT** a fashion photo.
- **Palette per-object:** honor each item's real Y2K color story (frost-wash denim, juicy velour
  pastels, paisley bandana red/blue, marabou hot pink, chrome-nylon puffer).
