# Learning-content ecosystem audit brief

**Status:** QUEUED PORTFOLIO REVIEW

Audit the current LIBRAiRY books, their structure, High/classes, episodes and
a representative NewsStand sample as one learning ecosystem while preserving
each format's distinct job.

## Inventory fields

| Field | Required |
|---|---|
| Product, route and canonical source | Yes |
| Topic and intended audience | Yes |
| Learning objective and prerequisite | Yes |
| Evidence/source and date sensitivity | Yes |
| Depth and correct mental model | Yes |
| Adjacent concepts and misconceptions addressed | Yes |
| Nuance, uncertainty and disagreement | Yes |
| Modality advantage | Yes |
| Analogy and limit | When used |
| Explanation/application/transfer checks | Yes |
| Overlap and whether repetition is instructional | Yes |
| Missing topic or step | Yes |
| Quality/accuracy/freshness risk | Yes |
| Recommended product home and next experience | Yes |

## Outputs

1. canonical content/concept map;
2. gap, overlap and substandard-content register;
3. keep/revise/merge/move/retire decisions;
4. product-specific build packets;
5. cross-product progression and handoff map; and
6. freshness/correction owners and review cadence.

NewsStand is assessed for its timely editorial job, not penalized for not
behaving like an evergreen book or class.
