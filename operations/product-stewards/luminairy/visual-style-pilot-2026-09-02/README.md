# LUMINAiRY portrait style reset — three-wing pilot

**Status:** CHARACTER TREATMENT PROMISING / FIRST BACKGROUND SYSTEM REJECTED / NEW MAiVEN PROOF UNDER REVIEW

**Date:** 2026-09-02

**Public effect:** None. No existing portrait, profile, receipt or public artifact was changed.

## Direct rulings

Ali rejected the current LUMINAiRY portrait collection as too realistic,
painterly and dark. This ruling supersedes the previous use of dark,
painterly stained-glass portraits for this product.

Ali found the brighter character treatment closer, then added a binding
consistency rule: every portrait within a wing must share the same background
system, or a tightly controlled variation in that wing's colour family.

Ali then rejected the first background-family attempt. The pale cream and
beige fields made the cards boring, the abstract linework did not read strongly
enough as stained glass, and the result had no specific LAiDIES identity. In
particular, MAiVENS must remain decisively in the blue family.

## Candidate rendering language

- grown-up editorial-comic illustration, not oil painting or photorealism;
- clear inked contours, simplified facial planes and flat cel-shaded colour;
- bright, graphic stained-glass geometry rather than a dark cathedral scene;
- waist-up framing with the face as the visual priority;
- person-specific likeness, age, hair and clothing remain evidence-bound;
- no candles, Gothic gloom, black background fields or decorative props;
- restrained paper/halftone texture is acceptable only when it does not read
  as brushwork or realism.

## Rejected background families

- **PATRON SAiNTS:** the Cher and Dionne / David Rose proofs attempted one
  luminous pink, cream and warm-gold rose-window family. Use the same rounded
  panel architecture, line weight, density and brightness. Regina remains the
  red Anti-Saint exception but keeps the same architecture and luminosity.
- **MAiVENS:** the Hannah Fry / Ada Lovelace proofs attempted one sapphire,
  pale-blue and cream sweeping-window family. Use the same curved geometry,
  line weight, density and brightness.
- **TRAiLBLAZERS:** the Allie K. Miller / Mira Murati proofs attempted one
  golden-amber, cream and restrained-teal angular-window family. Use the same
  faceted geometry, line weight, density and brightness.
- These backgrounds are rejected and must not be integrated or used as
  production references. Twenty-six generated batch files are preserved under
  `../rejected-visuals/2026-09-02-boring-beige-background-family-v1/`.
