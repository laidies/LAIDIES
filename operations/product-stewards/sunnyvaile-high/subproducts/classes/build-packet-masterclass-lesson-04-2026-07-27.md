# Build packet — Masterclass Lesson 4: From Chatting to Working

**Status:** BUILDING — bounded pilot content and script candidate; no filmed,
admitted, deployed or public class.

## Outcome

- **Product:** SUNNYVAiLE High Classes
- **Scope:** One pilot lesson inside the seven-lesson *Get the Best Out of
  Your AI Tool* pathway.
- **User problem:** A natural conversation accumulates requirements,
  corrections and decisions, but never becomes one current assignment or
  durable work record.
- **Intended outcome:** The learner can chat naturally, create a current brief
  before consequential execution, choose how to intervene in active work and
  checkpoint the result for continuation or clean review.
- **Evidence:** Reconciled intake; current official product documentation;
  research packet `chat-session-project-workflow-research-2026-07-26.md`;
  canonical concept-map row; existing class/episode/LIBRAiRY inventory.
- **Scope:** Content record, narrated visual script, controlled sandbox demo,
  one-page working brief, transfer scenarios, reshoot boundaries.
- **Non-goals:** Retelling Episode 2; teaching generic prompt engineering;
  completing all seven lessons; claiming one vendor interface is universal;
  filming private chats; admission, deployment or publication.

## Proposed direction

- **Decision:** Use Lesson 4 as the first pilot because it proves the
  masterclass's distinct practice value with fewer volatile menu dependencies.
- **LAiDIES fit:** “Chat naturally. Work deliberately.” respects how women
  already collaborate while revealing the invisible structure the interface
  does not teach.
- **External capability proposed:** None. Use the existing production stack.
- **Approval/installation required:** None for local content/script work.
  Filming may use only an authorized non-sensitive demonstration account.

## Measurement and learning

- **Baseline:** No admitted class and no learner evidence for this workflow.
- **Success:** An unfamiliar learner can produce a usable brief, correctly
  classify at least five of six transfer scenarios with reasons and resume in
  a clean session without relying on hidden chat history.
- **Failure:** She repeats labels but cannot distinguish the governing
  objective, session, Project or durable artifact; or she chooses intervention
  based on message wording rather than consequence.
- **Review date:** Before any filming, then again on the exact assembled tape.
- **Decision after measurement:** Revise, hold or advance the lesson; never
  infer whole-masterclass acceptance from the pilot.
