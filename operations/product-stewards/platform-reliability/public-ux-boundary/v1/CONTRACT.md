# Homepage public-UX boundary v1

**Status:** VERIFIED LOCALLY — RELEASE NOT PERFORMED

**Public presentation owners:** Town Entry and Brand

## Ruling

The readiness/current projection remains a backstage release-control artifact.
It may validate producer receipts, freshness, correction chains, exact route
identifiers, hashes and failure states for release operations. It is not a
Homepage content system.

The Homepage must not import the readiness runtime or projection, mount
readiness/current/receipt UI, render operational failure strings, expose
hashes, or translate destinations into “routes” as visitor-facing product
language. Platform output cannot supply public headings, explanation,
limitations, calls to action, status cards or visual composition.

An admitted weekly release may eventually provide structured editorial facts
through a separately accepted atomic interface. Town Entry and Brand still
own the words and presentation. A release fact does not become visitor copy by
being accurate.

## Failure behaviour

Missing, stale, conflicting or corrupt backstage state blocks release
promotion and produces internal evidence. The Homepage keeps its approved
evergreen presentation. It does not show a diagnostic card, receipt, hash,
failure code or “status unavailable” substitute.

## Acceptance

`test-homepage-public-ux-boundary-v1.mjs` binds the exact Homepage and runtime
bytes, proves the backstage files still exist unchanged, rejects any Homepage
runtime import or DOM mount, rejects the known contaminated vocabulary and
stale June 24 claim, and mutation-tests ten forbidden regressions.

This is local source evidence only. It does not deploy, publish, verify public
origin bytes, approve Homepage copy, or admit a future weekly episode module.
