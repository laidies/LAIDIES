## Controlled-provider execution contract

Each provider sheet must name exact endpoint/Worker/provider/account,
authoritative completion, stable idempotency key, timeout/unknown
reconciliation, retry, cancel/delete/unsubscribe/moderate/refund, retention,
abuse/rate/cost controls, accessible recovery, prohibited analytics data,
test identities, owner and rollback. Configuration or a successful request is
not delivery, join, post, answer, image or moderation completion.

## Release execution contract

The candidate manifest must bind commit, dependency lock, built artifact hash,
migration set/order, runtime assets, environment identifiers without secrets,
provider suite receipts, browser/native accessibility and performance results,
public-origin journeys, incident owner and rollback artifact. A deployment
does not promote itself to verified.
