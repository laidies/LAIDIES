## Existing class material to reuse

### Reuse as the Basics spine

`operations/classes/basics-what-these-tools-are.CONTENT.md` already provides
the best existing instructional structure:

- product, model, context and tools/retrieval are separate;
- model capability, product feature and account entitlement are separate;
- one product may offer several models or route among components;
- a search result is opened and checked rather than trusted because it looks
  like a citation; and
- the learner compares what changes when product, model, tool or context
  changes.

This is a strong class job because it can demonstrate the layers and let a
learner diagnose which layer changed.

### Replace before recording

`operations/classes/basics-how-it-works.CONTENT.md` was rewritten around the
same system map. It no longer teaches “the model is what writes,” “underneath
it is still just predicting words” as a complete explanation, “the newest
models check themselves” as a reliability guarantee, or a permanent split in
which search finds while generative AI writes.

The exact replacement narration for the current Basics Class 01 recording is
`operations/audio/class-basics-01-definition-replacement-2026-07-29.txt`.

### Class sequence worth keeping

1. **What these tools are:** identify product, model, context and tools.
2. **How the system handles one request:** follow
   `request → product instructions/context → model → optional tools → response`.
3. **Controlled comparison:** change one layer at a time and diagnose the
   effect.
4. **Evidence check:** open the exact source for one consequential claim and
   decide whether it supports the answer.
5. **Transfer:** show a new product surface and ask the learner to label the
   same layers without being told.

The Episode 01 Try-On can introduce comparison. The class owns the deeper
diagnosis and transfer practice; the Library owns the durable definition.

## 30 July writing-quality addendum

Primary research now owns the truth boundary, not the finished reader prose.
Every maintained concept treatment must separately supply:

1. the accurate plain-language definition;
2. the smallest useful mechanism;
3. why the reader should care;
4. an episode-native analogy with its limit; and
5. a memory line that is memorable without pretending to be the definition.

The surface jobs are also explicit: Episode creates the encounter; Trading
Cards support retrieval; Vocab supports lookup; Concepts supports depth; and
Classes own demonstration, diagnosis and transfer. The current Episode 01
cluster was rewritten and propagated on that basis. All four populated
Trading Card backs passed a local visual safe-area review after the maintained
learning link moved below the card rather than being squeezed into the artwork.
