## Learner job

A person has one repeatable task—such as preparing a weekly update, checking a campaign brief or turning meeting notes into an action list—and wants AI to follow the same useful process without rebuilding the prompt every time. She also needs to know whether a downloaded skill is safe, current and appropriate for the work it claims to perform.

## What LAiDIES should teach

### Skills are procedures, not staff

Anthropic defines a skill as a folder of instructions, scripts and resources that Claude loads when relevant. It can make a well-defined task more repeatable. It does not supply accountability, organizational context, professional licensure, final judgement or permission to act.

### Begin with one bounded, low-risk job

Choose a process the learner already understands and can judge. Name the input, steps, output, exclusions and success criteria. Do not begin with legal conclusions, financial decisions, unsupervised publishing, sensitive records or a whole “department.”

### Prefer self-authored or fully audited skills

Anthropic warns that skills may contain third-party packages or code and identifies prompt injection and data exfiltration as primary risks. Before enabling a third-party skill, read every included file, identify dependencies and external connections, inspect requested access and decide whether the source is trustworthy. A viral download count is not a security review.

### Test behavior, not the label

Run the skill on several representative examples, a deliberately awkward case and a case where it should not trigger. Compare results with the current workflow. Record failures and required human review. “Marketing skill” or “legal skill” is not evidence that the workflow is complete or correct.

### Maintain it like a working procedure

Version the skill, keep a rollback path, retest after relevant product/model changes and remove obsolete or conflicting instructions. Feed recurring, evidenced corrections through the separate draft/final classification workflow in `INTAKE-edits-to-reusable-ai-instructions-2026-07-31.md`.

## Intermediate lab outline — Build the Skill. Keep the Job.

1. **Pick the shift:** choose one repeated task with a human-verifiable result.
2. **Write the operating card:** define inputs, steps, output, exclusions and success criteria.
3. **Pack only what it needs:** add the minimum instructions, examples, resources and scripts; expose every dependency and permission.
4. **Run the dress rehearsal:** test normal, edge, non-trigger and failure cases with fictional or non-sensitive data.
5. **Keep a manager in the loop:** mark decisions and professional judgements that remain human-owned.
6. **Review the first week:** compare real approved outputs with the skill's output; classify corrections before revising it.
7. **Version or fire it:** keep, revise, disable or roll back based on evidence.

**Observable result:** The learner produces one self-authored, low-risk skill or platform-neutral workflow card, an audit record, a multi-case test set and a justified keep/revise/disable decision. She can explain why a procedure bundle is not an employee or a professional adviser.
