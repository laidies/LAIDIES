## Exact reviewed prose

### Give one repeat task a dress rehearsal—not the keys.

A reusable AI skill is a folder of instructions, reference files and sometimes executable scripts that can load when a matching job comes up. For a first try, make your own simple skill or use one from the product maker—not an unknown download. Give it one low-risk job you already know how to judge: turn fictional meeting notes into a draft action list; at home, use an imaginary trip for a packing list. Before it runs, inspect every file and limit the accounts, folders and internet access available to it. Then try a normal case, an awkward case and a request that should not trigger it. One polished answer proves only that one rehearsal looked good. If you cannot inspect it, limit it, judge it and stop it, do not give it real work.
