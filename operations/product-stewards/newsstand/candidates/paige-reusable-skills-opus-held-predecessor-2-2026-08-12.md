## Exact reviewed prose

### Give one repeat task a dress rehearsal—not the keys.

If you rebuild the same prompt every week, a reusable AI skill can keep that procedure ready. Its short description helps the AI match it to a request; its instructions, reference material and sometimes scripts may then load. That is useful—but a procedure is not a colleague. You still own the decision and the consequences. Start with a skill you made or one published by the company that makes your AI tool, not an unknown download. Even a first-party label is a starting clue, not a safety audit. Before testing, see which files and access it asks for. Connect only what this job needs; if it wants a client folder or the internet and you cannot explain why, decline. At work, rehearse with fictional meeting notes: a useful action list names the action, owner, date and unresolved decision. At home, try an invented weekend: a packing list should use the brief without asking for real bookings or email. Run a normal case, an awkward one and a request that should not trigger it. If one fails, fix the instructions and rerun the same cases—or leave the skill in rehearsal. One polished answer proves only that one rehearsal looked good. Basics P8 explains extra powers and access; Build the Skill. Keep the Job. owns the full rehearsal.
