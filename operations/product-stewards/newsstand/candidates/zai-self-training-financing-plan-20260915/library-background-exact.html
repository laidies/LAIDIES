5.2 — The Core Idea: Guess, Check, Adjust

📼 Rewind it: If you remember recording an answering-machine greeting, listening back, hating one word, and doing another take, the shape is familiar: attempt, compare, adjust, repeat. Training does this with maths and enormous amounts of data — not taste, embarrassment, or self-awareness.

You now know where training data comes from (Chapter 3) and how it gets chopped into tokens (Chapter 4). The system has its raw material. Now: how does it actually learn?

The entire process in one sentence: The system makes a guess, checks how wrong it was, adjusts itself slightly in the right direction, and tries again. Millions of times.

That's it. Every AI system you've ever used — from the spam filter to ChatGPT — was built by this loop. The details vary, but the principle never does.

Let's make it concrete. Imagine training a language model — the kind of system you chat with. During training, the system is given a sequence of tokens and asked to predict the next one. Over and over. Billions of times.

One round of the training loop:

  1. Input: The system sees the tokens: The cat sat on the
  2. Guess: It predicts the next token. Maybe it guesses chair.
  3. Check: The actual next token in the training data was mat. The system was wrong. How wrong? A loss function calculates the distance between its guess and the right answer.
  4. Adjust: The system adjusts its internal numbers slightly — nudging them in a direction that would have made mat more likely and chair less likely.
  5. Repeat: Next example. Next guess. Next adjustment.

After billions of these rounds — billions of guesses, billions of tiny adjustments — the system has tuned its internal numbers to be very good at predicting what comes next in text. Not because anyone told it the rules of English. Because it saw so many examples that it absorbed the patterns: grammar, facts, style, reasoning, everything that shows up in the statistical structure of language. The unofficial training anthem is Oops!... I Did It Again — except every oops comes with a number showing how wrong the guess was.

Important: this is how language models train. Other types of models learn differently.

The guess-check-adjust loop is universal — every type of model uses it. But what it's guessing varies:

  • Language models (LLMs): Predict the next token in a sequence of text. That's the task described above.
  • Image classification models: Look at an image and predict which category it belongs to ("cat," "dog," "stop sign"). The training task is: given this image, guess the correct label.
  • Text-to-image models (like Midjourney, DALL-E): You type "a 1990s library with neon lighting" and the system produces an image. These are trained on millions of image-caption pairs — the system learned what things look like by seeing countless examples of images paired with descriptions of what's in them. During generation, it starts from visual noise (like TV static) and gradually shapes it into an image that matches your description. (How this actually works mechanically — the full process — is Chapter 6.)
  • Recommendation systems: Predict what you'll engage with next (which song you'll play, which video you'll watch) based on patterns in your behaviour and millions of other users' behaviour.
  • Speech recognition: Predict which words correspond to a given audio signal.
  • Multimodal models: Can handle multiple types of input and output. You can show them a photo AND ask a question about it in text, and they'll respond in text. Or you can ask for an image and they'll generate one. These are trained on mixtures of text, images, audio, and video — all at once. Most frontier models in 2026 (ChatGPT, Claude, Gemini) are multimodal: they can read images, generate images, process audio, and handle text all in one system.

The core loop is always the same (guess → measure error → adjust → repeat), but the specific task — the thing being predicted — changes depending on what the model is built to do. In this chapter, we'll keep using language models as our main example because they're what most people interact with, but the principles apply across all types.

⏸️ Wait — the language model just predicts the next word? That's it? For the text part, yes. Every capability you see in a language model — writing essays, answering questions, writing code, reasoning about problems — emerges from training it to predict what token comes next. The richness comes from doing that one thing at extraordinary scale, across extraordinary amounts of data. But remember: language models aren't the only type. Image generators work differently (shaping noise into pictures). Recommendation systems work differently (predicting what you'll click). And multimodal models combine several of these abilities into one system. "Predict the next word" is the trick behind text generation specifically — not all of AI.
