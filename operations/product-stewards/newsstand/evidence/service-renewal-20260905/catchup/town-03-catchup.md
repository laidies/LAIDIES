# Missed a few days? Start with Catch Me Up.

Use Catch Me Up for a recent return; use the archive when you need one older thing.

On a new device, Catch Me Up starts with the last seven days. Once a NewsStand visit is saved on that device, it starts from that visit and shows the available stories and columns.

For a particular older piece, use the archive. Choose From and To dates, then narrow by topic, theme or concept.

Catch Me Up is for a quick return; the archive is for a deliberate search. The dates stay attached, so an older report does not quietly become today’s news.
