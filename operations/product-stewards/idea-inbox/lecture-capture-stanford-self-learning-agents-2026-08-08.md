### NOTE-001 — Standard prompting versus chain-of-thought prompting

**Ali's wording:** “standard prompting vs. chain-of-thought prompting.”

**Type:** concept distinction and practical technique; exact lecture claim,
example and timestamp not yet supplied.

**What is worth preserving:** LAiDIES should help a learner see that “write a
better prompt,” “ask the model to explain its reasoning,” and “use a reasoning
model” are not interchangeable instructions. The useful comparison is not a
collection of magic phrases; it is what information and work the user asks to
be visible, what computation the model/product may perform internally, and what
the resulting explanation can and cannot prove.

**Provisional teaching boundary — requires source verification:**

- standard/direct prompting asks for the task or answer using the necessary
  goal, context, constraints, material, examples and output requirements,
  without requiring an explicit intermediate rationale;
- chain-of-thought prompting asks for or demonstrates intermediate reasoning
  before a final answer, but the visible rationale must not automatically be
  described as a faithful transcript of the model's hidden internal process;
- a reasoning model may spend additional inference computation before
  answering even when the user did not request a visible step-by-step account;
  requesting a rationale and selecting a reasoning model are different choices;
- performance can depend on the model, product, task and current provider
  guidance. “Think step by step” is not a universal accuracy guarantee, and a
  plausible explanation still requires evidence or checking appropriate to the
  task.

**Existing LAiDIES overlap:** Episode 02 and Briefing 101 own prompt specificity,
context and delegation. AI Fundamentals 101 already owns the concepts Prompt
and Reasoning Model and the distinction between inference work and evidence
quality. The current repository has no exact treatment connecting direct
prompting, elicited rationale and hidden/internal reasoning. A prompting
freshness signal is already open, so this note must merge into that review
rather than trigger a duplicate rewrite.

**Classification:** `MERGE`.
