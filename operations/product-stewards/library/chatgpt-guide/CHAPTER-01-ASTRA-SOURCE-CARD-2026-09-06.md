# ChatGPT Guide chapter 1 — Astra refresh source card

**Checked:** 2026-09-06
**Scope:** only the model, effort, access and prompting claims changed by GPT-6
Astra. All unchanged chapter claims remain governed by the 2026-09-02 source
card. This is official-source research, not an account-entitlement test.

## Approved current claims

### The model ladder

The practical OpenAI ladder now has four task-fit choices:

- **Luna:** fast, economical work with clear repeated instructions.
- **Terra:** capable everyday work with a bounded job and some judgment.
- **Sol:** demanding professional work where depth and polish matter.
- **Astra:** the hardest cross-domain, code, application and research work
  where deeper synthesis, long context or tool use can materially change the
  result.

Astra is not the new default answer to every task. OpenAI's current guidance
still says to use the lowest effort that works and notes that smaller models can
be better choices for routine jobs.

**Official sources:** [ChatGPT models](https://learn.chatgpt.com/docs/models),
[latest model guide](https://developers.openai.com/api/docs/guides/latest-model).

### ChatGPT effort choices are not the API list

For eligible ChatGPT Power accounts, OpenAI currently lists Terra Light, Sol
Light, Sol Medium, Astra Light, Astra Medium and Astra Extra High. Availability
depends on plan, account, client and rollout. Max and Ultra are specialist
options and most people do not need them.

The Astra API has a different control: `low`, `medium`, `high`, `xhigh` and
`max`; it does not support `none`. Typing an effort name into a prompt does not
change a product control.

**Official sources:** [ChatGPT models](https://learn.chatgpt.com/docs/models),
[Astra API model card](https://developers.openai.com/api/docs/models/gpt-6-astra).

### Astra needs bounded instructions

OpenAI documents several Astra behaviours that affect a practical brief. It is
sensitive to long instruction stacks, can ask a focused question and stop, may
under-delegate, and may test a small task more thoroughly than it needs. For a
long job that can take several steps or use tools on your behalf, name the
authority order, say whether reversible work should
continue without another question, make delegation explicit where useful and
define the test boundary. These controls reduce wasted work; they do not promise
correctness.

**Official source:** [latest model guide](https://developers.openai.com/api/docs/guides/latest-model).

### Access and money

Astra is rolling out to eligible paid accounts. Enterprise access can require
administrator enablement. Exact model and effort controls can differ by plan
and rollout. ChatGPT access does not grant API access, and a model choice does
not grant file, app, connector, publishing or purchase permission.

The book will not print a fixed message allowance as a durable promise. It may
explain that Astra consumes more usage than smaller choices and direct readers
to the current account display. API prices, if mentioned to prevent confusion,
must be labelled as API prices rather than ChatGPT subscription prices.

**Official sources:** [ChatGPT models](https://learn.chatgpt.com/docs/models),
[ChatGPT pricing](https://learn.chatgpt.com/docs/pricing),
[Enterprise availability](https://learn.chatgpt.com/docs/enterprise/workspace-model-availability).

## Editorial application to the leadership-proposal case

The leadership-proposal case remains a Terra/Medium-sized job: three bounded
sources, a clear authority order and four outputs whose facts can be checked
against one another. Astra is introduced through a counterexample—a genuinely
larger job spanning many departments, contradictory records, connected outputs
and approved tools—so the chapter does not recommend Astra merely because it is
newest. Codex is not forced into this example; it belongs in a separate workflow
for a reader who actually has a website, app or repository.

Keep the line “High effort is a setting, not a tiara.” Follow it with the
mechanism: higher effort is useful when deeper synthesis or a lower setting's
named failure justifies extra time; without a bounded finish line, more effort
can produce more commentary and review rather than a better result.
