and where does my judgment belong?” Prose states the eight steps, but the visual
makes the loop, order and continuous human boundary visible at once.

## Pixel inspection

- All required main labels are spelled correctly in both final assets.
- The visible order is: choose task → allowed context → brief → inspect →
  verify → revise/restart → bounded delegation → save/reuse.
- The return path closes the loop rather than ending at delegation.
- “YOUR JUDGMENT + YOUR AUTHORITY” is an enclosing boundary, not a ninth step.
- Icons support the text and do not carry the mechanism alone.
- No provider mark, robot, fake interface or technical pseudo-label appears.
- The desktop composition uses the human hands and boundary to reinforce
  continuing authority. The mobile composition removes the hands to protect
  label size and scanning order while retaining the same glossy editorial
  object/card treatment and mechanism.
- The first mobile generation was rejected before repository intake because it
  added forbidden numbers and object text (`TASK`, `BRIEF`, `USE AGAIN`). The
  successor removes every extra character and retains the eight required labels.
- The first repository mobile asset was then rejected by independent review for
  drifting into a hand-drawn visual family. It remains preserved as
  `working-loop-mobile-v1-style-rejected.png`; the bound successor matches the
  desktop asset's glossy object/card treatment without changing labels or logic.

## Text equivalent

The manuscript states the complete loop immediately before the figure. Its alt
text names all eight steps and the enclosing judgment/authority boundary. The
caption explains the consequence: gaining tools or autonomy does not remove
human responsibility.

## Generation brief retained

The desktop brief required a wide cool-white LAiDIES textbook field map, eight
clockwise labelled stations, one enclosing human judgment/authority boundary,
large exact lettering, accessible contrast and no robots, circuitry, provider
logos, fake UI, beige poster field or pseudo-text.

The mobile brief required the same lesson in a separately composed portrait
layout for 358px display. The repair changed only the defect: it removed all
numbers and incidental object words while preserving the required labels,
objects, arrows, boundary, palette and spacing.
