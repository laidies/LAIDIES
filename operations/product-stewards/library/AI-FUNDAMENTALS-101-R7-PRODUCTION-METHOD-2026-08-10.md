# AI Fundamentals 101 R7 production method

**Status:** ACTIVE PRODUCER METHOD FOR INTRODUCTION + CHAPTER 1 R7

R7 preserves Ali's authored Introduction as the direct base and rebuilds
Chapter 1 from the whole-book prerequisite route. It does not patch, summarize
or visually restyle R6.

## Production sequence

1. Preserve the Introduction's three reasons, jokes, cadence and authorial flow.
2. Remove only the superseded Nerd-O-Meter promise; replace it with a truthful
   description of a complete core book and occasional local `Go deeper` notes.
3. Open Chapter 1 with the public confusion the chapter resolves, not a
   definition, classification framework or figure.
4. Establish one organising idea: public AI labels answer different questions
   about a system and therefore do not form one flat list or one nested family.
5. Orient the principal label families in an order a zero-prerequisite reader
   can follow: broad field; approach; job/result; information forms; operating
   pattern; physical interaction; breadth claim; evidence status.
6. Teach each label through the same familiar worked product so relationships
   remain visible. Use a different transfer case at the end.
7. Introduce no internal mechanism that depends on a later chapter. Tokens,
   features, parameters, calibration, attention, orchestration and inference
   belong later and are not used as shortcut definitions here.
8. Use the timeline to distinguish old idea, practical breakthrough, scale and
   access, and newly popular label. Do not imply a march toward AGI.
9. Use local `Go deeper` only when the core explanation is already complete.
10. End with reasoned Recognise, Explain, Draw and Use checks, Key Definitions,
    a compact source/freshness note and only real LAiDIES continuations.

## Analogy rule for this candidate

No analogy is mandatory. The VHS-shop example is admitted only for the bounded
job of showing several different AI jobs in one familiar service. It must map
cleanly to recognition, ranking and recommendation and remain understandable
to a reader who does not remember Blockbuster. It may not be used to explain
models, training or the entire AI ecosystem.

## Visual rule for this candidate

R7 contains no CSS-drawn diagram. The first direction-review render uses clear
textbook hierarchy, tables only where rows genuinely compare the same property,
and one deterministic timeline. A relationship diagram is commissioned only
after its exact claims pass semantic review; it must be a governed SVG or
raster asset with deterministic text, equivalent prose and separate visual
admission.
