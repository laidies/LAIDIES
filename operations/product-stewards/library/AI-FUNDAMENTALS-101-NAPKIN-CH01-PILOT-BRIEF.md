# AI Fundamentals 101 — Chapter 1 Napkin pilot

**Status:** COMPLETED TOOL TEST / REJECTED AS THE DEFAULT TEXTBOOK-VISUAL METHOD
**Tool tested:** Napkin AI free plan
**Public status:** NOT ADMITTED / NOT INTEGRATED / NOT PUBLIC

## Question tested

Can Napkin turn a short passage of Ali-vetted Chapter 1 prose into a visual that
explains the difference between ordinary software and AI without rebuilding the
logic manually?

## Exact source input

The final bounded run used **By pasting my text**, not **By describing my
idea**. The source was the exact 259-character `The Core Distinction` passage
from:

`content/library-books/pilots/ai-fundamentals-101-quick-manuscript/source/full-book.md`

> The Core Distinction. Automation: A person writes the rules → the machine
> follows them exactly. AI: A person supplies examples → the machine figures
> out its own rules. A person is involved in both. The difference is which job
> the person did.

Two broader attempts were discarded before judgment: one description-led
prompt and one full-Chapter-1 import. The first was the wrong test because it
substituted instructions for the vetted prose. The second gave Napkin too many
unrelated visual jobs and produced a generic chapter-summary candidate. Neither
is evidence for the final ruling.

## What Napkin produced

The exact-source run generated multiple editable comparison, relationship and
sequence layouts. The strongest inspected variants were:

1. opposing Automation and AI arrows;
2. one puzzled person branching toward Automation and AI;
3. generic side-by-side comparison symbols; and
4. sequence and relationship templates that changed arrangement without
   repairing the teaching mechanism.

The output was fast and editable, but the leading candidate replaced the
source's actual question with `Which technology should be used for the
project?`. It reduced the distinction to short suitability labels such as
predefined rules versus learning from examples.

## Acceptance result

**REJECT — not a useful textbook teaching visual.**

- It changed the lesson from `who supplies what` to `which technology should a
  project use`.
- It did not show the two causal paths: person writes rule → machine follows,
  versus people label examples → system learns patterns.
- The puzzled-face branch implied a reader or project choice rather than the
  different human job inside each mechanism.
- Icons and opposing arrows made a comparison look polished but did not carry
  the missing explanation.
- Repair would require rewriting the headline, rebuilding the arrows and
  inserting the missing inputs and transformations. That is manual diagram
  reconstruction, not an efficient generated foundation.
- No candidate reached mobile recomposition, export or LAiDIES styling because
  the teaching mechanism had already failed.

## Method ruling

Napkin is **not** the default automatic producer for AI Fundamentals textbook
visuals. It may still be useful after the instructional structure already
exists—for quick editable layout exploration, icons or a rough first
arrangement—but it did not perform the expensive job LAiDIES needs: choosing
and faithfully rendering the right teaching relationship.

This test does not reject BioRender, Genially, H5P or a native structured
diagram component. No purchase, export, textbook integration or publication
occurred.
