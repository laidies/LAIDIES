# Learning scan — sequence stop and header receipt hold

**Date:** 2026-07-26  
**Scope:** Visitor dossier only

## Qualifying surprise

A shared-header acceptance request supplied source, route and receipt
checksums. The source and route matched, but the first review associated the
receipt checksum with the Markdown evidence path. Platform's correction showed
that the checksum belonged to a separate immutable JSON maker receipt; both
files were unchanged and correctly bound once their paths were distinguished.

## Prevention rule

For a checksum-bound consumer acceptance, bind every checksum to its exact
artifact path and media type before concluding that bytes changed. A JSON
machine receipt and a Markdown narrative can describe the same candidate while
having different checksums. Stop at HOLD when a supplied path does not bind,
but preserve the distinction between “path association unresolved” and “bytes
changed.” A corrected exact path tuple is a valid fresh-review trigger.

## Sequence learning

When a new Ali sequence ruling narrows an active visual program, stop generation
at the next safe boundary and relabel already-created in-flight outputs before
any judging or recommendation. A generated image is not an admitted direction.
