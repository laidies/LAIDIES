# Reverse brief — Claude Opus 5

## Reader promise

Give a reader enough evidence to decide whether to test, wait, or ignore Opus 5 without calling a vendor benchmark a universal verdict.

## Exact editorial decisions

| Paper | It may say | It may not say | Current disposition |
|---|---|---|---|
| The Breaking | Opus 5 is live, costs the same base API rate as Opus 4.8, and changes the available top-end Claude choice. | It is the best model for everyone or a proven daily default for LAiDIES. | `HOLD_FOR_INDEPENDENT_REVIEW` |
| The Daily | Anthropic documents better difficult coding/review, long-context, vision and office-work capability; its current docs say settings inherited from earlier models should be re-tested. | Early practitioner friction is a population failure rate or proves a local workflow will fail. | `HOLD_FOR_INDEPENDENT_REVIEW` |

## Evidence versus inference

- **Evidence:** Anthropic announced availability on July 24; its launch page states the base API price, model placement, claimed capability comparisons, fallback behaviour and Fast mode terms. Its July 28-accessed effort/prompting docs describe effort controls and migration advice.
- **Evidence with interested-party limit:** claimed benchmark leadership, customer quotations, performance and safety statements are provider-selected evidence. They establish Anthropic’s position, not an all-workflow ranking.
- **Independent but limited evidence:** Every’s published test documents one team’s problems with instruction conflict, early stopping and existing skills/plugins. It is a real reported experience, not a prevalence estimate.
- **Inference:** a Claude user with difficult coding or knowledge work has a reason to run a controlled comparison before changing defaults.
- **Position:** do not switch models on launch language or one score; keep the task, inputs, acceptance checks and cost record constant.

## What must happen before a stronger recommendation

1. Run one representative LAiDIES task at `high` and the justified comparison level, with the same inputs and acceptance checks.
2. Record completed scope, correction count, elapsed time, total tokens/tool calls and fallback/effort setting.
3. Re-open Anthropic’s launch, effort and prompting pages on the proposed publication date.
4. Have an independent editor decide whether a current Daily has at least two distinct consequential developments rather than a padded release recap.
