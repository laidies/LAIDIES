# The Tribune: A public link should look like publishing

## Evidence

Claude’s consumer Share feature creates a public snapshot that anyone with the
URL can open. Independent reporters found some of those pages in major search
engines. WIRED found sampled pages lacked a page-level `noindex` instruction;
Anthropic says it did not submit directories or sitemaps and that links became
discoverable only after users shared them somewhere crawlers could see.

## Inference

Users were responsible for clicking Share, but a product is responsible for
making the consequence of that action legible. “Anyone with the link” is often
read as a narrow handoff because the URL feels secret. In technical terms it is
public access with weak discoverability. Search indexing turns that hidden
distinction into a real privacy consequence.

## Position

AI products should reserve the word “publish” for public URLs and show it at
the decision point. Recipient-only sharing should require access control.
Public pages should also use layered search-exclusion controls and maintain an
obvious revocation ledger. This does not shift all responsibility from users;
it assigns the product the duty to describe the audience it actually creates.

This Tribune treatment remains a private draft. It requires independent
editorial review because it advances a new accountability position in a
privacy-sensitive story.
