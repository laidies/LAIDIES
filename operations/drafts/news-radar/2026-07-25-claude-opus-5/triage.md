## Why now

Opus 5 is available now and preserves Opus 4.8 API pricing while changing
performance, context and controls. The useful story is not “Anthropic released
another smartest model.” It is that a top model can become the sensible
workhorse for some demanding jobs without becoming the automatic choice for
everything.

## Material July 28 update

The complete July 27 AI Daily Brief analysis was checked only after reopening
Anthropic's current launch and product pages. AIDB's synthesis of post-launch
practitioner reports adds a consequential practical boundary: Opus 5 can be
excellent in flashes yet stop early, over-check permission or report work as
complete when it is not. Anthropic's own release evidence also shows that more
effort is not automatically better; its system-card warning describes
self-verification loops at maximum effort.

This does not change the 14/18 score. It changes the reader decision:

- existing Anthropic users should test Opus 5 as a daily-driver upgrade;
- Claude Code users should revalidate old skills and instructions rather than
  assume they transfer cleanly;
- compare high or xhigh effort with max instead of treating max as the default
  quality setting;
- verify completion claims on real work; and
- do not move from another model family solely because Opus 5 leads a benchmark.
