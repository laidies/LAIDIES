# The Breaking: Claude Opus 5 changes the top-end Claude choice

Anthropic released Claude Opus 5 on July 24. It is available across Claude's
paid products and API, and its API price stays at $5 per million input tokens
and $25 per million output tokens—the same as Opus 4.8.

This belongs in The Breaking because the model choice changed now. Opus 5
combines stronger agentic knowledge-work performance with a one-million-token
context window, effort controls and an optional fast mode. People choosing a
Claude model for demanding research, coding or document work have a new option
to test at the previous Opus API price—but the first post-launch evidence says
the settings and instructions around the model can matter as much as the label.

Think of it like a coffee shop replacing its most experienced everyday barista
with a more capable one while leaving the menu price unchanged. That does not
make the most elaborate drink the right order every morning. The useful
question is still what you need, how long you can wait and what the full order
costs. Fast mode is the rush surcharge; effort controls how much work goes into
the order.

In Rewind Era terms, it is a stronger desktop computer at the same sticker
price, with a Turbo button that costs extra to use. The analogy stops there:
models are variable systems rather than fixed-speed hardware, and results still
depend on the task.

## What changes for readers

- Test Opus 5 if you already use Claude for demanding multi-step work or very
  large document collections.
- Compare it with a cheaper current Claude model before making it the default.
- If you use Claude Code, retest old skills and instructions. Anthropic says
  the 5-series setup was substantially simplified, so inherited prompting can
  conflict with the new model.
- Compare high or xhigh effort with max. More effort can become repeated
  checking rather than a better answer.
- Verify that requested work is actually complete. Post-launch practitioner
  reports collected by AI Daily Brief describe stopping early, excessive
  permission checks and premature completion claims.
- Measure outcome quality, elapsed time and total token use—not only benchmark
  rank.
- Do not assume that selecting the label proves every request used Opus 5.
  Anthropic says safety-flagged requests can fall back to Opus 4.8 in
  Claude.ai, Claude Code and Cowork.

Independent evaluation supports strong agentic knowledge-work performance, but
no benchmark proves it is best for every reader's files or workflow.
Practitioner reports are useful warning lights, not a representative failure
rate; launch stability and workflow setup may explain some of the problems.

What to watch: real-use comparisons, total cost at different effort settings,
plan limits, completion reliability and any change to predecessor
availability.
