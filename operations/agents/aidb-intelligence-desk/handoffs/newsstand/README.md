# NewsStand handoff inbox

This directory contains AIDB Intelligence Desk signals for the NewsStand
editorial radar.

One developing story keeps one file:

`YYYY-MM-DD-[existing-newsstand-story-key].md`

Follow `../NEWSSTAND-INTERACTION-CONTRACT.md`. An empty inbox is a valid quiet
state. Files here are private intake records, not editorial acceptance,
publication approval, or public content.
