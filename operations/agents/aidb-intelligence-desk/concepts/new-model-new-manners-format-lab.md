# New Model, New Manners — format lab

**Status:** FORMAT TEST — no canonical product or channel selected  
**Core job:** Rapid, trustworthy orientation when a consequential model release
changes how ordinary people should work with AI.

## The function before the format

Each edition must help someone answer:

1. What actually changed?
2. Is this model for my job?
3. Which old interaction habit should I retire?
4. What should I try differently today?
5. How will I know whether it worked?

That function is stable even if the container changes.

## Format hypotheses

| Shape | Distinct job | Strength | Risk |
|---|---|---|---|
| **Model Fitting Room broadcast** | Timely orientation and demonstration | Feels like useful public-service radio/TV; quick to update | Too brief for skill-building |
| **Radio dispatch / podcast insert** | Explain the “new manners” conversationally | Intimate, fast, reusable in weekly audio | Harder to show before/after output |
| **Public-TV demonstration** | Show one task on old and new settings | Makes model differences visible | More production effort; can date quickly |
| **Interactive clinic** | Let the learner choose a task and receive a fitting | Practical and personalized | Requires product logic and maintenance |
| **Tip card** | One memorable action for today | Highly shareable and fast | Easily stripped of evidence and caveats |
| **Mini-course/workshop** | Practise several changed behaviours | Strongest for durable skill | Too heavy for every release |
| **Living Model Wardrobe update** | Preserve current cross-provider choice guidance | Durable source of truth | Not an event or teaching experience by itself |

## Leading package to test

**Model Fitting Room** — a five-to-eight-minute public-service edition that can
exist as audio and video:

- the release in one plain-language sentence;
- “wear it for / leave it in the wardrobe for” task fit;
- one inherited habit to retire;
- three evidence-backed new manners;
- one visible before/after fitting;
- source and “checked on” line;
- one practical card;
- invitation to the deeper clinic/workshop only when warranted.

This is a hypothesis, not a title or format decision.

## Format decision test

Use the GPT-5.6 setup lesson as the pilot material and compare:

1. a 90-second radio dispatch;
2. a five-to-eight-minute public-TV-style demonstration;
3. a 15-minute practical mini-lesson;
4. one interactive before/after fitting.

Judge comprehension, immediate usefulness, evidence visibility, production
load, updateability, accessibility, and whether the audience can correctly
apply the lesson to a new task. Do not choose from aesthetics alone.

## Evidence gate

Every format uses the same verified packet: current provider guidance, exact
original practitioner sources found through AIDB, explicit model/product
boundaries, a representative LAiDIES test, limitations, and a freshness
trigger. The format may compress the presentation but never erase provenance.

## NewsStand handshake

Every model-release edition begins as one shared evidence packet with two
possible reader jobs:

- **NewsStand:** what launched, who can use it, what choice changed, what is
  confirmed, and what remains uncertain now.
- **Model Fitting Room / learning treatment:** which old habit to retire, how
  to interact differently, and what a learner can practise.

NewsStand decides whether the dated story qualifies. The learning owner decides
whether the practical treatment earns a format. Either side can say no without
forcing the other to manufacture an artifact. When both proceed, they reuse
source and claim identifiers, link between treatments, and avoid repeating the
same explanation.
