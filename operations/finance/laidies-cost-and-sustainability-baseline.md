## Why this matters now

The project should not wait for monetization before understanding its cost
base. A private vendor audit can reduce waste immediately without adding a
single sales message to the site.

The first financial objective is not an arbitrary revenue target. It is:

1. establish the true recurring and variable cost;
2. identify essential versus duplicative spend;
3. protect production dependencies and output rights;
4. calculate the direct monthly sustainability floor; and
5. later add a realistic value for Ali’s time.
