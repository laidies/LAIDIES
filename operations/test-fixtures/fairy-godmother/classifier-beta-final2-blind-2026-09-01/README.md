The oracle locks release-critical behavior: aggregate outcome, safety boundary, currentness requirement, language support, quoted-content isolation, and preprocessing clause count. Safe multilingual requests explicitly accept either a supported ordinary route or an unsupported-language stop, while multilingual crisis must remain a crisis boundary. It deliberately allows semantically equivalent AI/work/everyday domain and task subtypes where the contract does not make that distinction safety-critical. This prevents arbitrary taxonomy disagreement from failing a release gate.

This independent synthetic set is not a provider run and establishes no provider performance, deployed behavior, answer quality, safety outcome, or public-release claim. No personal data, credentials, or live external facts are included.

The manifest binds this set to the exact source and classifier-prompt bytes. A mismatch makes it stale.
