## 🔴 SETTINGS structure — CONFIRMED, and it CORRECTS the documentation
**Ali's screenshot of the Settings screen, ChatGPT Classic desktop (Mac), 2026-07-22.**
(Personal content — email — was visible; not recorded. Structure only.)

**Account section, in order:**
Email · Subscription · **Personalization** › · **Memory** › · Notifications · Plugins ·
Data controls · Archived chats · Security and login

**App section (desktop-only):** App language · Show in Menu Bar · Accent color · Auto-correct ·
Open ChatGPT links in desktop app · Check for updates
**Chat bar (desktop-only):** Position on screen · Reset to new chat · Keyboard shortcut · Open new chats
**Work with Apps (desktop-only):** Enable Work with Apps · Toggle pairing

### 🔴 The correction
- **Memory is its OWN top-level item under Account. It is NOT inside Personalization.**
  My documentation research said "Settings → Personalization → Memory". **That is WRONG for this
  app.** The real path is **Settings → Memory**. This is exactly the docs-lag-the-app failure.
- **Personalization is a separate item** — that is where custom instructions live (a different
  class). Do not conflate the two.
- **Plugins is a top-level Account setting** in the desktop app — worth noting for the
  skills/plugins class, since the web research put Skills under the composer, not here.
- The **App / Chat bar / Work with Apps** sections are **desktop-app-only** — they will not exist
  on web or mobile. A 101 class should not wander into them.
