## 2. The irreducible core — what every course above includes

- A short **"how it actually works" conceptual segment** — even the demo-first Vanderbilt course reaches it by video 4. NOBODY skips this entirely.
- **Prompting as a discrete, named skill**, taught before anything else procedural (custom instructions, memory, agents, connectors).
- A **responsible/ethical-use segment** — present in every general-audience course found (Google AI Essentials module 4, Microsoft 365 Copilot module 1, Anthropic Claude 101 implicitly via "capabilities & limitations," GitHub Copilot Fundamentals module 1). Placement varies (first vs. mid-course) but presence is universal.
- A **capstone or "putting it together" close** — Claude 101 module 4, Vanderbilt's final capstone assignment, DeepLearning.AI's course summary.
- **Certificates** on every course found. This is table stakes now, not a differentiator.

## 3. What only the good ones include

- **A named cognitive framework, not just a feature tour.** Anthropic's AI Fluency course (Delegation/Description/Discernment/Diligence) is the only one in this set that teaches a transferable thinking model rather than a sequence of buttons. It is explicitly built to be model-agnostic and released under Creative Commons for other educators to adopt — a strong signal of what "serious" looks like.
- **Role-based or task-based tracks**, not one-size-fits-all: OpenAI's three-tier pathway (Foundations → Applied → Agents) and Anthropic's audience-specific variants (educators, students, nonprofits, small businesses, builders) both branch by who the learner is, not just what the tool does.
- **Explicit cost/tradeoff framing** — DeepLearning.AI's "cost intuition" module (prompting vs. fine-tuning, RAG vs. pretraining) is the only place in this set that teaches learners to reason about *why* you'd choose one capability over another, not just how to click it.
- **A worked capstone that forces synthesis** — Vanderbilt's final "Creating a Prompt-based Application" and Claude 101's "use-cases by role" both make the learner apply everything, not just recognize it.

## 4. What no course in this sample covered — the gap

Specific, not general:

- **No course found sequences memory, custom instructions, and projects together as a deliberate progression for a beginner.** The one place this ordering exists explicitly (OpenAI's "Customizing ChatGPT": Custom Instructions → Prompt Engineering → Memory → GPTs/Projects) is a standalone *resource*, not confirmed to sit inside the actual AI Foundations course sequence — NOT VERIFIED as part of the core pathway. Claude 101 does not mention memory or custom instructions by name at all in its published syllabus.
- **No course teaches what happens when the features conflict or overlap** — e.g., what wins when a Project's custom instructions disagree with account-level custom instructions, or when memory contradicts what's in a Project's files. This is exactly the kind of "where does it actually break" material a hands-on video class could own, and it appears nowhere in any syllabus found.
- **No course walks the settings sidebar as a guided tour** — every syllabus found teaches features task-by-task ("write a prompt," "start a project") rather than location-by-location ("here is Settings, here is what each pane does"). That is a real gap if the deliverable is "where things are and how to set them up on the real screen," which is explicitly LAiDIES' stated aim per this project's brief.
- **Connectors are consistently the last or near-last topic**, when covered at all (Claude 101 module 3 of 5, near the end; not found as a named topic in any of the Google, Vanderbilt, or Microsoft-365-Copilot syllabi). NOT VERIFIED whether this is deliberate sequencing (connectors are genuinely advanced) or simply that connectors are newer than most of these syllabi and got bolted on late.
- **No course aimed at general adult learners addresses cross-tool comparison** — none of the syllabi found teach "here is the same task in Tool A vs Tool B, here is why the interface differs." Every course is single-vendor.

## 6. Who these are aimed at

- **Developer-first, explicitly**: Microsoft Learn's GitHub Copilot Fundamentals (roles listed: DevOps Engineer, Administrator, Developer, Solution Architect, Student), Anthropic's Claude API / MCP courses.
- **General knowledge-worker, not developer**: OpenAI Academy's whole three-course pathway, Anthropic's Claude 101 and AI Fluency track, Google AI Essentials, Microsoft 365 Copilot Fundamentals, Vanderbilt's Prompt Engineering course (explicitly "no prior knowledge of AI or coding" — same claim made for DeepLearning.AI's course).
- **Nothing found in this pass is built specifically for non-technical women.** Anthropic's AI Fluency track has audience variants for educators, students, nonprofits, and small businesses — the closest thing to demographic tailoring found anywhere — but none of it is gender- or confidence-level-targeted. This corroborates the brief's premise: general "beginner-friendly" courses exist in volume; something built for a smart adult who has specifically been made to feel behind by tech does not appear to exist among the sources checked. Cannot rule out its existence elsewhere — this is an absence-of-evidence finding, not a confirmed gap across the whole internet.

## 7. Concept-first vs. doing-first — the live sequencing question

Findings are genuinely mixed, which is itself the finding:

- **Concept-first, clearly**: Google AI Essentials (module 1 is entirely "what AI is/isn't" before any tool), Anthropic AI Fluency (module 2, "Deep Dive: What is Generative AI?," precedes all framework/practice modules).
- **Doing-first, concept folded in early but after a demo**: Vanderbilt's course opens with two worked examples before its "What are Large Language Models?" video (video 4 of the course). DeepLearning.AI opens with "Welcome," then goes straight to "How Generative AI works" as video 2 — concept arrives almost immediately, but the course doesn't linger on it before moving to writing/reading/chatting practice within the same first module.
- **No course found delays concept material to the end.** In every syllabus reproduced above, whatever conceptual material exists is front-loaded into the first module or first 15–20 minutes, never held back as a late "now that you've used it, here's the theory" section.

Best-supported answer to the live question: **serious courses lead with concept, but keep it short — a single video or module, rarely more than 10–15 minutes — before moving to hands-on practice inside the same first session.** None of the corroborated syllabi support either extreme (no theory at all, or a long theory block before any doing).

## What the good tutorials/courses do well
- Keep individual lesson units short (3–15 min) regardless of total course length.
- Put responsible/ethical use inside the course, not bolted on as a disclaimer.
- The best (Anthropic AI Fluency) teach a transferable framework, not a button tour, and say so explicitly (built to be model-agnostic).
- Role/audience branching (OpenAI's three-tier pathway, Anthropic's audience variants) rather than one course for everyone.

## What they all get wrong
- None found sequence memory, custom instructions, and projects as a deliberate, connected progression — they're either omitted, or listed as a flat feature list rather than "when do you reach for which one."
- None walk the settings surface as a location-based tour — all are task-based, which leaves "where do I even click" — precisely what this project set out to fix — unaddressed.
- Several of the syllabi used to write this file could only be reconstructed from search-engine snippets and secondary blog summaries rather than a full direct fetch of the vendor's own page (Google Prompting Essentials, Microsoft 365 Copilot Fundamentals module 5) — a caution about how much even "serious" course catalogs publish in text form for something like this research pass to check against.

## Already covered to death
- Basic prompting technique (personas, few-shot, chain-of-thought) — five of the eight courses researched teach this at length; Vanderbilt alone spends four of six modules on named prompt patterns.
- "What is AI / how do LLMs work" at a conceptual level — present, well-trodden, and short in every course.
- Responsible-use / bias / privacy disclaimers.

## The gap
Sequencing memory, custom instructions, projects, and connectors together as a single deliberate progression for a genuine beginner, tied to a location-based tour of the actual settings screen — not found, anywhere, in this research pass.
