## Why this matters
Every generic guide teaches **prompting**. Almost none explain the account-level machinery —
what a Project actually is, what memory really retains, what a connector can reach. That makes
it genuinely differentiating material rather than something a reader could google
([[laidies-differentiation-vs-guides]]). It is also the difference between a tool that feels
generic and one that feels like it knows you.

## The topics
Per tool (ChatGPT · Claude · Gemini · Copilot · Perplexity), using the vendor's own term:

| Topic | The question a reader actually has |
|---|---|
| **Memory / personalisation** | What does it keep? Where do I see it, edit it, wipe it? What does it NOT remember? |
| **Custom instructions / profile** | Set once, applies everywhere. What belongs here vs in a single prompt? |
| **Projects / Spaces / Gems / GPTs** | A container with its own files and standing instructions. When is one worth making? |
| **File upload & knowledge** | What happens to my file? How long does it live? Limits? |
| **Connectors / integrations** | Drive, email, calendar — what access does it REALLY get, and how do I revoke it? |
| **Extensions / plug-ins / skills / MCP** | What is each vendor's version? Free tier? What do I ask before enabling one? |
| **Automations / scheduled tasks** | Where can it act on a schedule? |
| **Modes people miss** | Voice, canvas/artifacts, code execution, web search. |

For each: **what it IS** in one plain sentence · **how to set it up**, concretely ·
**what it's genuinely good for** · **the ONE mistake** people make with it.

## Where it lands
- **Setup 101** owns most of it — "set up once so every tool knows how you work" is exactly
  this, and is currently briefed far too narrowly (custom instructions only).
- **The per-tool books** (ChatGPT, Claude, Gemini, Copilot, Perplexity) each cover their own
  version and what's free vs paid.
