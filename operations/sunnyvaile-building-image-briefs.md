# SUNNYVAiLE Building Image Briefs

*Drafted 2026-06-29. For commissioning building exteriors via Codex / image generation. Each entry: function (what the building does on the site), and 2-3 sentences of visual direction.*

---

## Visual register (canon)

**Two registers — don't mix:**

1. **Sacred / Character art** (locked benchmark) — patron saint cards, Girl Talk card faces, Mme CLAi-O portrait. Plum + pearl + gold filigree + enamel pendant feel, Victorian-fairytale, halos and stained glass. *Per Ali's locked visual style benchmark.*
2. **Y2K mall / suburban signage** (this doc) — town buildings, environmental signage, street view. Chrome + glitter + holographic stickers + bubble type + Bedazzler treatment. Pink + plum + hot pink + cyan + lime accents, Caboodle/iMac-translucent textures, real-world small-town buildings *modified by the local Y2K teens.*

**Common rule:** Y2K specificity is what makes this work. Drop the gold filigree. Add butterfly clips, glitter pen graffiti, holographic stickers, Bedazzler rhinestones. Each building should feel like the town's official structure got customized by SUNNYVAiLE High's class of '99.

## Codex prompt pattern (recommended)

For each building, structure the prompt as:

```
[Building name and function as the subject], Y2K suburban small-town storefront aesthetic — real-world building modified by the local Y2K teens.

Composition: [exterior building, dusk lighting / golden hour / midday — specify].

Y2K register details (must include 2-3): chrome trim, holographic stickers, butterfly clips, glitter pen graffiti, Bedazzler rhinestones, bubble 3D lettering for signage, pink + plum + cyan + lime accents, glossy plastic textures, Lisa Frank decals, Caboodle-translucent panels.

Specific building cues: [pull from the visual description above].

Avoid: Victorian enamel pendant, gold filigree, pearl strings, Bridgerton register. This is mall era, not ball era.
```

Then add building-specific details from the brief above.

## Open questions

1. **Style consistency** — commission these as a SET (one artist / one prompt-pattern) so they read as a coherent town, OR commission individually with the same brief but allow variation?
2. **Format consistency** — landscape (good for page headers) or square (good for tile thumbnails) or both per building?
3. **Day vs. night** — pick a time-of-day per building (Bronze at night, Blend & Snap at morning, etc.) or all at same time for a unified "town walking tour" feel?
