## Job

Measure whether Luna, Terra, Sol and Astra are being assigned to the right
LAiDIES work. This is a real-work calibration, not a synthetic model contest.
It exists only to change routing decisions that affect quality, review burden
or cost.

## What counts

Record one row at the end of each completed Tier 1 or material Tier 2 task.
Exclude simple questions, one-step mechanical maintenance, waiting and tasks
whose outcome cannot yet be judged. A task with several agent lanes receives
one foreground row; note materially different lane models in the route field.

Use only observable evidence:

- **Model / effort:** actual foreground model and any material supporting route.
- **Why routed:** the task characteristic that justified the route.
- **Time band:** `<15m`, `15–60m`, `1–4h` or `>4h`; do not invent precision.
- **Usage evidence:** exact task-specific usage only when the product exposes
  it; otherwise `UNAVAILABLE`. Do not infer task cost from an account-wide
  percentage change.
- **First pass:** `YES`, `NO` or `NOT YET JUDGABLE`, measured against the
  original acceptance conditions.
- **Corrections:** count only material maker-found, reviewer-found or Ali-found
  issues; identify repeated known defects separately.
- **Detour:** note unnecessary architecture, process or output that was removed.
- **Cheaper route:** `LIKELY`, `UNLIKELY` or `UNKNOWN`, with one evidence-based
  reason. This is a counterfactual judgment, not a measured fact.

## Decision rule at review

Move a task class down when a cheaper model clears the same acceptance bar
reliably. Move it up only after a named failure that stronger reasoning could
plausibly have prevented. Do not promote Astra because it feels impressive or
demote it because one task used substantial credits. Compare like task classes,
not unrelated outputs.
