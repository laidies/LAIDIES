# Brand Assets

Logos, wordmarks, icons, doodles, and reusable brand graphics.

## LAiDIES Wordmark Colour Rule

When LAiDIES is manually typeset in any designed asset, keep the `Ai` rose and the rest of the letters black/mulberry. On dark backgrounds, adjust the non-rose letters to the appropriate light/cream equivalent while preserving the rose `Ai` contrast.

Use the approved logo assets whenever possible. Do not recreate or fake the logo when a real asset is available.
