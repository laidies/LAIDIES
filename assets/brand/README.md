# Brand Assets

Logos, wordmarks, icons, doodles, and reusable brand graphics.

## LAiDIES Wordmark Colour Rule

When LAiDIES is manually typeset in any designed asset, keep the `Ai` rose and the rest of the letters black/mulberry. On dark backgrounds, adjust the non-rose letters to the appropriate light/cream equivalent while preserving the rose `Ai` contrast.

Use the approved logo assets whenever possible. Do not recreate or fake the logo when a real asset is available.

## Current web authority

For current web and interactive work, do **not** choose a wordmark by browsing
the asset directories. The current authority is the live Jost 800 wordmark in
`index.html` and `content/site/sv-topbar.css`.

The older `laidies-wordmark-final-b-{light,dark}.*`,
`laidies-logo-header-approved-v6.png` and
`laidies-logo-masthead-approved-v3.png` files are retired for new web use even
when historical copies remain under `approved-assets`. See
`operations/product-stewards/brand-experience-director/CURRENT-WORDMARK-AUTHORITY-2026-07-27.md`.
