## 01 · From chatting to working

[No narration. On screen: Chat naturally · make the current brief · intervene on purpose · checkpoint the work]

## 02 · The chat can discover the job.

Messaging an AI tool like a friend is not the mistake. Conversation is useful when you are still discovering the job. The trouble starts when this window is also expected to be the idea box, the brief, the workbench, the review and the permanent record.

## 03 · Available context is not governing authority.

The old rule was simple: this chat holds the context, and a new chat starts from zero. Current tools can carry saved instructions, memory, Project sources and earlier conversations across boundaries. More information may be available. That still does not tell the model which objective, decision or version governs the work.

## 04 · A plausible start is not the approved plan.

We begin naturally. The tool receives one useful request, and the model produces an early draft. It fills a gap with app registration because nobody has said otherwise. That is a plausible start, not the approved plan.

## 05 · Ten corrections do not become one brief by magic.

Now the real job arrives in pieces. Each correction is sensible. Together, they are easy to misread because the first draft is still sitting underneath them. Ten scattered corrections are not automatically one unambiguous assignment.

## 06 · Same facts. One current brief.

Pause before substantial execution. Keep every fact, but name one current authority. The objective, approved facts, boundaries, outputs and finish line now sit together. We have not written a giant perfect prompt. We have turned discovery into a brief the next stage can actually follow.

## 07 · Organize the work around the current brief.

Same tool. Same task. Same facts. One variable changed: the work is organized around the current brief. The model no longer has to infer which old message wins. We can execute in bounded stages and check each result against the same finish line.

## 08 · One coherent stage at a time.

The same session is useful while the objective and artifact remain coherent. Finish one stage, check it, then continue. A new message can revise this work without forcing a new chat, as long as it still serves the same governing brief.

## 09 · The rule is consequence—not punctuation.

While the run continues, four thoughts arrive. Make a poster afterward belongs in the queue. Use the venue's approved accessibility wording steers now because the current result depends on it. The audience is vendors, not neighbours stops the run because the premise is wrong. Why that heading can wait if the answer will not change the deliverable. The rule is consequence, not punctuation.

## 10 · Stay, reset, review, branch or project.

Stay when the objective and main artifact are unchanged. Start fresh when a distinct workstream begins or the old session is anchored to the wrong brief. Use a clean session for independent review. Branch to explore an alternative without overwriting the main line. Use a Project when several purposeful sessions need the same scoped home, sources and instructions.

## 11 · Save what is current and what happens next.

The transcript can explain what happened. The durable artifact records what is current. Save the accepted version, decisions, status and next action. Then a new session can resume from a handoff instead of reconstructing the job from confident fragments.

## 12 · Chat naturally. Work deliberately.

Chat naturally. Then orient, discover, brief, execute in stages, review and checkpoint. Let work finish, queue, steer or stop based on consequence. Continue or reset based on the objective and source of truth.

## 13 · Bring one real, safe job.

Complete the working brief for one safe job before the next substantial stage.
