# Mall interior candidates — 2026-07-24

These are **installed design candidates**, not Ali-approved art locks.

All ten images were generated with OpenAI ImageGen for the current Mall page-construction pass. The approved Episode 04 Heroine face lock was supplied as the mandatory rendering reference; each shop's current storefront was supplied only for shop identity and 1990s mall context.

Shared art direction:

- mature, dimensional graphic-novel realism;
- bright daytime mall light;
- light cream ground with midnight blue structure;
- vivid pink, purple, cyan, teal, cobalt and mint with smaller coral/orange accents;
- yellow and red remain minor;
- no people unless supplied later from an approved source;
- no readable generated text, logos, hearts or obsolete chip-heart motifs.
