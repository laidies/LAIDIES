The Classes

The planned format is one short screen-recorded demonstration per skill: a classroom, a named lesson on the board, and a tape on the AV cart. No class tapes are available yet. The written production previews below show the proposed objective and demonstration plan; they are not finished or editorially approved classes.

Each tool is a subject, and each subject runs eight periods. Each one covers a single topic, so when a menu gets renamed — and these tools rename things constantly — one tape gets re-shot instead of a lesson going stale.

These are the ones you have to see. If you could get it from a paragraph, it is a book and it lives in the LIBRAiRY instead.

A tape may be marked ready only when it has a real video, a filmed date and a current verification date. The current register has no ready tapes.
